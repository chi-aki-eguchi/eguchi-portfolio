# 途中の写真表示機能を現行へ統合

2026-09-28。依頼「未公開のというか、途中のものをどうにかして」に対応。

## 完了させる対象

`feature/photo-aspect` の機能を現行mainへ移植。旧版の丸ごとの置き換えではなく、変更を適用して現行の多対多シリーズAPIに合わせた。PDF・写真中心の構成・自由編集・Aboutの元比率表示を保持。

| 使える機能 | 場所 |
|---|---|
| トップ写真・表紙を切り抜かずに表示 | サイト編集 → サイトデザイン → 各ページの構成 → 写真の見せ方 |
| 拡大写真の余白（標準・少し余白・額装） | 同上 → 写真の入る大きさ |
| スマホの最大列数1〜4、PC最大12列 | 写真一覧のレイアウト。トップ側は個別指定か一覧から継承 |
| 行間を広く取るコンタクトシート | 写真一覧のレイアウト |

既定値は既存表示を維持。元から切り抜かない「写真中心」の表示には、従来構成向けの切り抜き設定は不要。写真の枚数と最小幅によって、実際の列数は指定上限より少なくなる。

仕上げ時に、スマホ列数の継承先の誤表示、カルーセルに残る黒い余白、全画面カルーセルで名前が余白へ外れる問題も修正。新しい写真設定はプレビュー・保存・再読み込みの経路へ統合。

## 旧試作の扱いを確定

- `prototype/b2-uneven-rows`: 高さの異なる行の仮想スクロール実験。現行の `library-contact-sheet.ts` が行ごとの高さ・表示範囲・矢印移動を担当している。古い別計算器は採用終了とし、二重実装を持ち込まない。
- `prototype/finder-contact-sheet`: 2026-07の読み取り専用の別画面実験。写真比率を保つ一覧・画面外の仮想化・詳細確認は現行の写真一覧に存在。別入口、別の詳細リスト、イベント別グループ表示は今回の商品へ採用しない。これらを実装済みとは扱わず、試作自体は終了。元ブランチは比較・復旧用に残す。
- PDF・写真集・検索と相談・stage1監査の各作業は既にmainの祖先。保存用PDFブランチは統合前の履歴。進行中の実装として数えない。
- 主checkoutの未コミット個別Vite設定、レビュー資料、顧客検証環境は保持。古い試作ブランチの削除・原本削除は行わない。

これで上記の試作は「統合する機能」と「採用を終了した実験」に決着。料金・契約、実クラウド、第三者購入・本人更新・印刷確認は別の販売運用事項で、この統合によって完了とはしない。
