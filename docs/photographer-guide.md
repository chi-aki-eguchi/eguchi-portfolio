# サイトを受け取った方へ

あなたの写真・文章・シリーズは、合意した内容で設定済みです。まず納品カードのサイトURLを開き、名前・写真・問い合わせ先を確認してください。未設定の項目があれば担当者へ伝えます。

## 入口とログイン

納品カードにある**あなた専用の管理画面URL**を開きます。Portfolio Kitの販売者の管理画面ではありません。パスワードは、URLやこのガイドとは別の合意した安全な経路で受け取ってください。サイトごとに別の値を使います。

忘れた場合は納品カードの担当窓口へ連絡してください。現行版には自動再設定メールはありません。担当者が本人確認後、そのサイトの管理用パスワードを変更し、再起動・旧ログインの失効・新ログインを確認します。作品データを消す必要はありません。通常のメール本文でパスワードを送らないでください。

## 最初の10分

1. 管理画面の「写真」から、試しに1枚取り込みます。カメラ原本は手元に残してください。Web用の保存画像は最大長辺3200pxへ最適化され、原本保管の代わりにはなりません。
2. 写真を選び、題名や説明を直します。公開の切り替えと保存状態を確認します。下書き・非公開の写真は一般公開されません。**公開中の写真・プロフィール等の保存は、公開サイトにも反映されます。**
3. 写真一覧で並べ替えます。保存完了を確認してから、別タブの公開サイトを再読み込みします。
4. 「サイト」のプロフィールを直し、保存後に公開ページを確認します。
5. ログアウトしてもう一度ログインします。画像・文章・並びが残っていれば、担当者へ利用確認を伝えてください。

パソコンではドラッグ、スマートフォンでは画面にある移動・選択の操作を使います。端末により操作が違う場合は、納品時にその端末で一緒に確認します。画面が狭い場合は詳細欄を閉じると写真一覧へ戻れます。

保存中に閉じたり、エラー後に何度も送り直したりせず、画面の通知を確認してください。失敗した内容・時刻・秘密が映らない画面を担当者へ伝えます。写真の削除は、他の作品集からの参照にも影響します。ごみ箱の復元可能期間と完全削除を区別し、原本は必ず別に保管してください。

## PDF作品集を利用する場合

契約に含めた検証済み範囲のみ利用できます。現行版は提出用／写真集、A4縦横、1枚／2枚の組、ページ順・回転・大きさ・説明の調整とPDF生成に対応しています。これは自由配置機能の最終仕様ではありません。

本は**そのブラウザー内**に保存します。現在は30冊・1冊20枚の試作上限があり、端末間同期はありません。編集後は「ブラウザーに保存」に加えて、メニューから「作品集ファイルを書き出す」でJSONを保存してください。JSONには画像が入っていません。担当者にJSONを渡して画像・DBと同じバックアップへ含めてもらいます。端末のデータ消去前に必ず書き出してください。

「印刷用」は解像度優先のPDFデータです。紙の本の納品、PDF/X、CMYK、塗り足し、製本、応募先への自動適合を意味しません。試し刷りと印刷所の要項確認は別途必要です。Webの写真順と本のページ順は独立しています。

## 費用・困ったとき・終了

初期制作費、サーバー・ドメインの実費、任意の作品更新代行、保守・操作相談は納品カードと合意済み条件確認書を参照します。月額9,800円の任意更新作業を、24時間監視や無期限のサーバー保守と読み替えないでください。

バックアップの対象・頻度・期間・窓口は契約で確認します。ブラウザーだけにある本はサーバーのバックアップに入りません。復旧作業は担当者が別環境で確認してから実施します。

終了・移管を希望するときは、契約を削除する前に窓口へ連絡し、写真・文章・設定・作品集JSONとPDFの持ち出しを確認してください。公開停止、最終請求、ドメイン移管、作業コピーとバックアップの保持期限を個別に確定します。すでに公開・ダウンロードされたコピーの回収は保証できません。
