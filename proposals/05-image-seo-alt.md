# 企画書 #05 — 画像SEO / alt運用（IG外で最大の発見経路）

状態: **提案（運用 + 小さな将来コード提案）** ／ 起案 2026-06-14 ／ 区分 A+B

## 1. なぜ重要か
写真家にとって **Google画像検索は IG 以外で最大の新規発見経路**。サイトは画像サイトマップ213件を
吐けるが、検索エンジンに「この写真は何か」を伝える情報が薄いと、見つけてもらえない。

## 2. 現状の根本課題（コードで確認）
**写真ごとの `title` / `description` が入っていないことが、全ての弱さの根。** 1つの欠落が3箇所に波及：
1. **alt** … `PhotoGallery`/`Lightbox` とも `photo.title || photo.meta || "Photograph"`。
   title 空だと全画像が `alt="Photograph"`（英語・全部同一）＝画像SEO的にほぼ無価値、a11yも弱い。
2. **画像サイトマップ** … `server.ts` の `imageTag` は `p.title` がある時だけ `<image:title>` を出力。
   title 空 → loc だけの裸エントリ。`<image:caption>`（説明）は現状未出力。
3. **ライトボックスのキャプション** … title が無いと作品名が出ない。

→ **逆に言えば、写真ごとに title（＋できれば description）を入れるだけで3つが同時に強くなる。**

## 3. 提案A（秋さん運用・コード不要・最優先）
- **公開写真すべてに title を付ける**（admin の meta編集）。
  - 良い title = 被写体 + 場所/文脈 + 少しの空気。例「夕暮れの逗子海岸、波打ち際の少女」。
  - 英語名より**自然な日本語**で可（日本の検索流入が主なら）。固有地名は強い。
- **description（任意）** に一言加えると caption/将来の image:caption に効く。
- **Search Console 登録 + sitemap 送信**（#A 既出）→ 画像インプレッションを計測できるようになる。
- 全部一度は無理なので、**まず代表作・シリーズ表紙から**。GA4 で見られている写真を優先。

## 4. 提案B（将来コード・承認後に個別実装企画化）
小さく安全な改善候補（今回は提案のみ）：
1. **alt フォールバックの改善** … `title || description || ${category}の写真 / 江口秋` のように、
   最低でも「写真」と分かる日本語に。ただし**全画像同一altは避ける**（category や seriesで少し差を）。
2. **画像サイトマップに `<image:caption>`** … description があれば caption も出力（loc+title+caption）。
3. **per-image ImageObject 構造化データ**（重め・効果は中）… 主要写真のみ対象にするなら検討。
→ 1・2 は小さく確実。3 は費用対効果を見て判断。

## 5. やりすぎ注意
- altに**キーワード詰め込みはNG**（スパム判定）。あくまで「写真の素直な説明」。
- title を SEO目的で不自然にしない。design-spec の佇まいと、人が読んで自然かを優先。

## 6. 効果の見え方
- Search Console「検索パフォーマンス → 画像」でインプレッション/クリックを月次確認。
- title を入れた写真から順に画像検索流入が立ち上がるはず。**content とSEOが一致する稀な施策**（良い説明＝良いalt＝良い検索）。

## 7. 秋さんへの確認
1. title/description を**日本語主体**でよいか（海外も狙うなら英語併記の方針）。
2. 提案B-1（alt フォールバック改善）と B-2（image:caption 追加）を実装企画化してよいか
   （小さく安全。承認あれば別サイクルで仕様→実装）。

→ 提案A（写真に title を付ける）はコード不要で今日から効く。最優先。
