## メモ

- Stripe の Payment Link は「公開おまかせ」1本に絞る。旧「自分で立てる」
  （¥10,000）のリンクは Stripe 側で無効化（アーカイブ）する。
- 設置リンクはオーナーが設置作業をするときだけ使う内部ツール。購入者・公開ページ・
  README には決して載せない。
- 文面は固定でも動きますが、購入者の名前を差し込めるなら冒頭を「◯◯さん、ありがとう
  ございます」にするとより丁寧です。
- 英語版はオーナーが手動で送り分ける。判断しづらい場合は、日本語版と英語版を同じ
  メールに併記してよい。
