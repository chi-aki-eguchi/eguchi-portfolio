相談できる3つの調整

01 / 見た目

屋号・ロゴ・色

利用権のあるロゴや屋号、指定色を、閲覧画面や出力へ反映。読む文字と操作の分かりやすさも確認します。

02 / 入れる情報

入力欄・呼び方

作品情報や案内文の項目名・補足欄を調整。既存データを使う場合は、互換性と移行方法を先に確認します。

03 / 渡すかたち

一覧・印刷・出力順

既存の出力を、提出先の列順や印刷用途へ。外部サービスとの自動連携は別の作業です。

個別見積り・合意してから着手

対象の道具と版、変更点、完成条件を確認して料金と納期をお伝えします。道具の本体代と調整費を分け、契約前に総額を確認します。見積り相談だけで支払いは発生しません。

汎用の新規システム、決済・会員機能、24時間監視はこの受付の対象外です。

お渡しするものと確認

  • 合意した変更を加えたファイル
  • 変更箇所・使い方・元版へ戻す手順
  • 合意したブラウザと入出力の確認結果

本体の更新をカスタム版へ自動反映する保守は含みません。原本・秘密情報・顧客データは初回相談には不要です。

START WITH ONE CHANGE

まず「ここが一つ変わったら」を。

例：「展示の台帳に管理番号を足し、一覧へ出したい」。実データを送らず、架空の例で希望を共有できます。AI・プログラムを補助利用し、制作物の表示と動作を確認します。
