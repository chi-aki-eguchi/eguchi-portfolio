# Photographer Guide

このガイドは、サイトを受け取った写真家本人向けです。

むずかしい設定は、セットアップ担当者が先に済ませています。
あなたが触るのは、基本的に管理画面だけです。

## 受け取るもの

セットアップ担当者から、次の3つを受け取ります。

1. サイトURL
2. 管理画面URL
3. 管理画面のパスワード

## 最初にやること

管理画面URLを開いて、パスワードでログインします。

ログインしたら、まず **「はじめに」** タブを開きます。
そこに、公開までに必要なことが順番に出ます。

## 入れるもの

最初はこの順番で大丈夫です。

1. サイトの名前
2. プロフィール
3. 連絡先
4. 写真
5. 公開する写真
6. トップ写真

写真の見え方は、最初から細かい文字設定を触るより、
写真の順番と S / M / L のサイズ指定を整えるほうが効きます。

## 公開前に見るところ

セットアップ担当者と一緒に確認します。

- トップページに代表写真が出ている
- ギャラリーが空白や壊れた画像になっていない
- プロフィールが本人の内容になっている
- 問い合わせ先が正しい
- スマホで名前やメニューがはみ出していない
- SNSでURLを貼った時の表示が本人の名前と説明になっている

## 触らなくていいもの

次の言葉が出てきても、写真家本人が普段触る必要はありません。

- GitHub: サイトのファイル一式を置く場所
- Railway: サイトをインターネットに公開する場所
- Turso: サイト名や写真一覧を保存する場所
- R2: 写真ファイルを保存する場所
- 環境変数: パスワードや接続先を書く非公開の設定メモ

困ったら、管理画面の「はじめに」で未完了になっている項目から確認します。
