EXHIBITION / WEB CHECKLIST

展示の案内は、
来る前と、帰ったあとに。

写真展のWebページは、会場への案内にも、見た作品を思い出す場所にもなります。用途を二つに分けると、載せる情報と順番を決めやすくなります。

来場前の人には、迷わないための情報を

最初の画面に展示名・会期・会場を置きます。「何時までか」「休みの日はあるか」「予約は必要か」は、写真を何枚もスクロールしなくても分かる場所へ。料金・予約の要否は主催者に確認した内容だけを書きます。

  • 展示名、作者・参加者、会期と開場時間、休廊日
  • 会場名と住所、公式のアクセス案内へのリンク
  • 入場料・予約の要否、問い合わせ先
  • 変更のお知らせを掲載する場所

作品を見た人には、題名と続きを

写真だけでなく、作品名・年・短い説明を並べると、来場後にも探し直せます。会場のキャプションとWebの表記を揃え、作品ごとの情報を同じ台帳から取り出すと、直し忘れを減らせます。

会期後の案内も、公開前に用意する

会期が終わったら冒頭を「終了しました」に変更し、訪問者が過去の開催情報を現在の予定と読み違えないようにします。作品紹介は残すのか、問い合わせ先は使い続けるのかも決めておきます。

公開前に、スマートフォンで5つ確認

  1. 最初に展示名・日時・会場が分かる
  2. 地図・予約・問い合わせのリンクが正しい
  3. 縦写真も横写真も意図した範囲で見える
  4. 作品名が写真と対応している
  5. 会期後の更新担当が決まっている

表示できたことと、予約・問い合わせが実際に届くことは別です。実送信の確認は、受付担当と合意して行ってください。

自分で一つの展示ページを作るなら

「ひとつの展示」は30枚までの写真と作品情報から、HTMLの展示ページを作る買い切りの道具です。2,980円。サーバーや独自ドメイン、公開作業は含みません。まず3枚の無料版と出力見本で、用途に合うか確かめてください。
