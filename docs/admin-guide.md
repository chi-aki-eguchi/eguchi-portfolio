# Admin Guide

管理画面 (`/admin`) の機能一覧と使い方。

## ログイン

1. `/admin` にアクセス
2. `ADMIN_PASSWORD` 環境変数に設定したパスワードを入力
3. 7日間セッションが有効（Cookie ベース）

セキュリティ: 10回連続失敗で15分間ロックアウト。

## スマホでの基本操作

画面下の「写真」「見せ方」「サイト」「設定」から移動します。「設定」は直接開きます。設定内では上部の「設定項目」を押すと一覧が開き、「メール」「並び順」「フォント」などで検索できます。

写真一覧では「選択」「並べ替え」「取り込む」が上部にあります。写真をタップすると、編集する写真と「基本・分類・詳細」が表示されます。項目を編集して下部の「保存」を押します。「変更なし」は、まだ変更していない状態です。保存に失敗したときは同じ帯から再試行できます。

並べ替えが使えない場合は、操作帯に理由が表示されます。公開側が日付順などになっている場合は「公開する並び順の設定を開く」から確認します。

## タブ一覧

### はじめに

初回セットアップ用チェックリスト。完了項目は自動で折りたたまれる。

### 写真

- **アップロード**: ドラッグ＆ドロップまたはファイル選択。300MBまで。JPEG/PNG/WebP/HEIC/HEIF/TIFF/AVIF対応。確認画面で「デジタル写真／フィルムのスキャン」と日時を確認し、取り込みを開始します。
- **自動処理**: サイト用に最大3200pxのJPEGを作成し、元ファイルのExif・XMPから日時を読み取ります。元のTIFやRAWは手元で保管してください。
- **重複検出**: 同一画像の再アップロードはハッシュで検出、スキップ
- **編集**: タイトル、メタ情報、カテゴリ、カメラ/レンズ、撮影日、表示サイズ(S/M/L)
- **一括操作**: 複数選択 → 公開/非公開、カテゴリ変更、シリーズ割り当て、サイズ変更、ヒーロー追加/削除
- **並び替え**: ドラッグで手動並び替え。設定で日付順・アップロード順も選択可
- **複製**: 同じ画像を複数カテゴリ/シリーズに配置（ストレージは共有）

#### フィルム・TIFの日付と並び順

デジタル写真ではカメラの撮影日時、フィルムではカメラ複写・スキャナーの日時を使います。フィルムのExifを、フィルムそのものを撮影した日とは扱いません。カメラの `DateTimeOriginal` を優先し、ない場合はデジタル化日時を使います。

Exif日時がない写真は空欄のまま取り込み、「日時が新しい順」「日時が古い順」のどちらでも末尾に表示します。取り込み時に「ファイル更新日を使う」を明示的に選ぶこともできますが、編集や書き出しの日時である可能性があります。ファイル更新日を使った写真は、編集画面にその出所を表示します。

一覧の上部に現在の並び順を表示します。「ファイル名順」（連番を考慮）も選べます。「今回追加」は手動表示のときにまとめ、日付順などを選ぶとその順序を優先します。「日付なし」の件数を押すと該当する写真だけを探せます。

**すでに取り込んだ写真は、日付のために削除する必要はありません。** 写真編集の「詳細」から「元ファイルから日時を読み直す」を開きます。一括の場合は写真を選択し、一括操作の「その他」から同じ操作を選びます。元ファイルをこの端末内で読み取り、ファイル名が一致した写真の日時を確認してから更新します。拡張子が異なる場合も名前が一意なら対応できます。同名が複数ある場合やExif日時がない場合は変更しません。画像・分類・手動の掲載順は保持します。

TIFに編集日時しかない場合は、それを撮影日へ置き換えません。日時を持つ複写元のJPEG／RAW、または書き出す前の写真が必要です。元ファイルにも日時がなければ、確認できる日付を手動で設定します。

### カテゴリ

ギャラリーのフィルタータブ。追加・削除・並び替えが可能。
カテゴリ削除時、所属写真は「未分類」に移動。

### シリーズ

写真をまとめたコレクション。

- **作成**: slug（URL用）、タイトル、サブタイトル、ステートメント
- **カバー写真**: 指定なしの場合、最初の公開写真を自動使用
- **テーマ設定**: シリーズごとの並び順（inherit/manual/date_desc/date_asc/upload_desc）
- **公開/下書き**: 非公開シリーズは管理画面のみ表示

### ヒーロー

トップページのヒーロー画像を管理。

- 写真一覧から追加、ドラッグで並び替え
- 表示モード: carousel / single / quiet-grid / editorial / immersive

### 料金プラン

サービスページの料金表。タイトル・価格・説明・特徴・備考を設定。

### サイト設定

- **基本情報**: サイト名、プロフィール名、自己紹介
- **作風を選ぶ**: 配色・書体・配置をまとめて下書きへ適用するプリセット。個別の設定も引き続き調整できます。
- **デザイン**: 背景色、文字色、フォント（Google Fonts / カスタム）、文字サイズ・間隔・太さを公開ページへ反映。
- **ナビゲーション**: 位置（top/left/bottom）、ホバー効果（fade/underline/dot/blur）
- **テクスチャ**: 紙質感（none/grain-fine/grain-coarse/paper）
- **SNS**: Instagram、X、note のリンク
- **SEO**: サイト説明、Google Search Console 検証コード、公開URL
- **外部連携**: Formspree（問い合わせフォーム）、note RSS、プリント販売リンク
- **ラベル**: ナビ・セクション・ボタンのテキストをすべてカスタマイズ可

### ゴミ箱

ソフトデリートされた写真。30日後に自動パージ（ストレージからも削除）。
復元またはパージ（即時完全削除）が可能。

## プレビュー

設定変更は保存前にプレビューへ反映されます。PCでプレビューを開くと、設定一覧を「設定項目」にまとめ、編集欄の幅を確保します。項目名や「メール」「並び順」などで検索して切り替えられます。境界のドラッグと「幅を戻す」で編集・写真の面積を調整できます。

「PC幅」は幅1280px以上のサイトをプレビュー枠に縮小して表示します。枠が狭くてもスマホの配置には変わりません。「スマホ幅」は375pxです。「大きく表示」からも「編集に戻る」で戻れます。未保存の変更と保存ボタンはプレビュー側にも表示します。

HEROの構成、ギャラリーの配置・列数・余白、配色、書体、ナビゲーション、登場する動きは、選んだ設定に沿って公開ページとプレビューへ反映されます。写真アプリへの表示切替は廃止しました。写真の指定・公開順や保存済みのデザイン設定は保持されます。

## Libraryの選択とキーボード操作

「選択」を押すと、一括操作の欄に「すべて選択」「選択解除」が現れます。すべて選択は、画面外も含む現在の一覧が対象です。絞り込み前に選んだ写真は保持し、一覧の外にある選択枚数も表示します。解除はその写真も含めて解除します。選択中の「選択」タブをもう一度押しても、選択は消えません。

| 操作 | 動作 |
| --- | --- |
| 写真をクリック | 閲覧中は編集を開く。選択中は追加・解除 |
| ⌘ / Ctrl ＋クリック | 閲覧から複数選択へ。選択中は追加・解除 |
| Shift ＋クリック | 最初の写真から範囲選択。起点を保持し、範囲を広げたり縮めたりできる |
| ⌘ / Ctrl ＋ A | 一覧をすべて選択 |
| ⌘ / Ctrl ＋ Shift ＋ A | 選択解除 |
| 矢印キー | 前後・上下の写真へ移動。選択中は移動先の1枚を選択 |
| Shift ＋矢印キー | 範囲選択を拡大・縮小 |
| Enter | 閲覧中の写真を編集 |
| Space | 写真を拡大確認。選択中も選択を保持。もう一度押すと戻る |
| Escape | 拡大や編集を閉じる。選択中は選択を終了 |
| ? | 操作キーの一覧。上部の「?」からも開ける |

検索や文章の入力中は、文字入力の操作が優先されます。スマホの一括操作欄は写真一覧の下にあり、最後の写真にも重ならず操作できます。並べ替え中の矢印は写真の順番変更に使うため、範囲選択は「選択」で行います。

## Libraryで写真を見ながら操作する

2026年9月7日の改善で、写真と操作欄の置き方を変更しました。

- **絞り込み**：PCでは写真一覧の横に開きます。スマホでは専用パネルが開き、上の「×」または下の「○枚の写真を見る」で一覧へ戻れます。カテゴリー・シリーズ・撮影方式を先に表示し、公開状態や未入力項目などは「その他の条件」、スマートアルバムは「保存した絞り込み」にあります。条件は閉じても維持され、「すべて解除」で戻せます。
- **写真編集**：写真を押すと、広い写真表示と編集欄を持つ画面へ切り替わります。PCでは写真の右側、スマホでは写真の下側で「基本・分類・詳細」を選びます。保存と元に戻すは下端にあります。
- **拡大と移動**：「写真を大きく見る」で画面いっぱいに確認でき、閉じると編集に戻ります。編集画面上部の矢印で前後の写真へ、「一覧に戻る」で元の一覧位置へ戻れます。未保存のまま移動・終了すると確認が出ます。キャンセルすれば入力内容を維持します。
- キーボードではEscapeでパネルを閉じられます。写真の編集中は、入力欄からのEscapeも未保存確認を通します。

写真の色調補正やRAW現像を追加したものではありません。写真の原本を保ち、公開・分類・説明などを編集する作業画面の改善です。

## HEROの写真を探す

HERO画面の下側で候補を検索できます。写真名・ファイル名・カメラなどで探し、追加が新しい順／古い順、撮影日、名前、Libraryの保存順へ並べ替えられます。この並び替えは候補の表示だけに適用され、公開中のHEROの順番は変わりません。

「絞り込み」でカテゴリーと写真の向き、「選択済みだけ」で現在のHERO候補を確認できます。一覧の密度は「小さく・標準・大きく」から選びます。目のボタンは拡大確認、写真本体はHEROへの追加・解除です。追加・解除はすぐサイトに反映されます。

上の写真の帯がHEROの表示順です。帯の写真を選ぶと、移動先・前後・先頭末尾・取り消しの操作が出ます。保存に失敗した場合はエラーを確認し、再実行してください。


### 写真を一度に見渡す

Libraryの見出し付近で表示を変更できます。「行組み」は、写真を切り抜かず、同じ高さの行へ並べる表示です。隣のスライダーで表示密度を調整できます。写真の公開側のS/M/L設定とは別の、管理画面だけの表示です。

「グリッド」は列数を選ぶグリッドです。PCでは2〜12列、タッチ端末では2〜6列を選べます。画面に収まる列数が上限です。PCの「自動」は表示メニュー内のサムネイルサイズに従います。並べ替え中は移動操作を置くため、既存のグリッド表示へ切り替わります。

サイズを変えるときは見ている写真付近を保ちます。行組みでは上下キーが隣の行の近い写真へ移動し、左右キーは前後の写真へ移動します。写真を押すと編集画面になり、「一覧に戻る」で元の一覧に戻れます。


## 公開ページの写真の見せ方

公開TOPは「Heroの見せ方」とトップ掲載写真の設定に従います。カルーセル、1枚絵、静謐グリッド、エディトリアル、没入型を選べます。HEROの写真と作品一覧の選定は別々に管理します。

公開Galleryの列数・余白・写真の大小・並び順はAdminで調整します。訪問者向けに追加していた列数変更・撮影日ソート・ガラスの操作欄は外しました。カテゴリーの選択や拡大表示は引き続き利用できます。スマホの入口は「写真を探す」です。

写真の拡大は「閉じる」、前後ボタン、左右キー、スマホのスワイプに対応します。Adminの一覧密度・HERO候補の検索やソートは、写真管理のための操作として残ります。
