# 管理画面 & サイト 改善リスト
## Admin Panel & Site Audit — 江口秋 ポートフォリオ

---

## A. フロントエンド（公開サイト）

### 🔴 優先度：高

#### 1. Galleryページに見出しがない
- About→「Contact」、Contact→「Contact」のように見出しがあるが、**Galleryページだけ見出しなし**で直接写真グリッドが始まる
- 他ページとの統一感がない

#### 2. Contact ページのテキスト色がハードコード
- 「Contact」見出し、説明テキスト、メールアドレス、Instagram / X リンクが全て `#bbb` で固定
- Settings の TEXT カラー設定が反映されない
- テーマカラーを変更した時に色が合わなくなる

#### 3. About ページの英語名の色がハードコード
- 「Aki Eguchi」が `#999` で固定（Settings で制御できない）
- 他のテキスト要素は CSS 変数化済みなのにここだけ残っている

### 🟡 優先度：中

#### 4. TOPページ → Recent Work のレイアウト
- 写真が3枚しかないため、2列目の右側が空白のまま
- 写真が少ない場合のレイアウト（1列、等間隔グリッドなど）を検討すべき

#### 5. ページタイトル（document.title）が変わらない
- SPA なのでどのページに遷移しても `<title>` が同じ
- ブラウザのタブやブックマークで区別がつかない
- SEO にも影響（各ページ固有のタイトルが必要）

#### 6. Gallery の写真に情報がない
- タイトル、撮影日、カテゴリなど何も表示されない
- クリックしても拡大表示（ライトボックス）がない
- 写真家ポートフォリオとしてはインタラクションが少ない

#### 7. フッターの著作権年が「2025」固定
- 現在2026年なので自動更新にすべき（`new Date().getFullYear()`）

#### 8. 「View all」リンクの視認性
- 「Recent Work」と「View all」の文字が非常に薄い（opacity 30%）
- デザインとしては良いが、リンクだと気づかない可能性がある

### 🟢 優先度：低

#### 9. モバイル最適化の確認が必要
- ハンバーガーメニューの有無が未確認
- ヒーロー画像がモバイルで切れないか

#### 10. パフォーマンス
- メインバンドル 459KB — コード分割の余地あり
- 静的アセット（`/assets/*`）に Cache-Control ヘッダーがない
- 画像のレスポンシブ対応（srcset）未実装

---

## B. 管理画面（Admin Panel）

### 🔴 優先度：高

#### 11. Settings ページが長すぎる
- テキスト設定・色設定・フォント・タイポグラフィが全て1ページに縦並び
- スクロール4画面分ある
- **セクション折りたたみ（アコーディオン）** または **サイドタブ** にすべき
- 現状の構成：
  - サイト情報（名前、フッター、コンタクト）
  - テーマカラー
  - ヒーロー文字スタイル
  - フォント
  - タイポグラフィ（6カテゴリ）
  - パスワード

#### 12. Save ボタンが最下部にある
- タイポグラフィを変えてもセーブするには最下部までスクロール必要
- **sticky（固定）ボタン** にするか、各セクションに Save を付けるべき
- 変更があった場合のみボタンを目立たせる（色変更・パルスなど）

#### 13. 未保存変更の警告がない
- 設定を変更した後、他のタブに移動しても警告なし
- 変更が失われるリスクがある

### 🟡 優先度：中

#### 14. Categories タブの UX が紛らわしい
- 「No categories yet」と表示されるが、フォームに「Street / street」がプリフィル済み
- ユーザーは「Street というカテゴリがある」と勘違いする
- プレースホルダーテキスト（例：「例：風景」）にすべき

#### 15. Library — 写真管理機能が不足
- ドラッグ＆ドロップで並び替えができない
- 一括削除ができない
- 写真をクリックしても詳細編集パネルがない（タイトル、カテゴリ割当、説明）
- 写真のメタ情報（ファイルサイズ、アップロード日）が見えない

#### 16. Hero タブが単機能すぎる
- 画像アップロードだけ — 1タブ使う必要がない
- Settings に統合するか、ヒーロー文字設定もここに移動して「ヒーロー設定」として統合すべき
- 現状：ヒーロー画像は Hero タブ、ヒーロー文字色/サイズは Settings タブに分かれていて分かりにくい

#### 17. Profile タブの Save ボタンの位置
- Profile もスクロールが必要で Save が下にある（Settings と同じ問題）
- Bio が空のまま → About ページに説明テキストがない

#### 18. Live Preview の挙動
- Settings の「Live Preview」はサイトプレビューが横に表示されるが、他タブ（Library, Hero, Profile）には同等機能がない
- Hero 画像を変更した場合、即プレビューが見られない

### 🟢 優先度：低

#### 19. Admin Password セクション
- 「Set via environment variable: `ADMIN_PASSWORD`」と表示
- 技術者以外には意味不明
- せめてパスワード変更フォームがあるべき（DB に保存して環境変数をフォールバックに）

#### 20. ログイン画面
- パスワードのみ（ユーザー名なし）— シンプルだが、複数人管理には対応できない
- パスワード表示/非表示トグルがない

#### 21. タブのアクティブ状態
- 現在のタブがどれかは分かるが、視覚的な区別がもう少し強くてもよい（下線やハイライト）

## C. コード・技術的な改善

### 🟡 優先度：中

#### 22. CSS 変数の統一が未完了
- Contact ページのフォームラベル、SNSリンクがまだハードコード（`text-[#bbb]`）
- About ページの英語名がハードコード（`text-[#999]`）
- Gallery ページの見出しが存在しない（追加時に CSS 変数化が必要）

#### 23. admin.tsx が 1,300行超
- 1ファイルに全タブの UI が入っている
- タブごとにコンポーネント分割すべき（LibraryTab, HeroTab, SettingsTab 等）
- メンテナンス性・可読性が低い

#### 24. 画像最適化パイプラインがない
- アップロードされた画像がそのまま配信される
- WebP/AVIF 変換、サムネイル生成、サイズ制限チェックがない

#### 25. エラーハンドリング
- API エラー時のユーザーフィードバックが不明確
- ネットワーク切断時の挙動が未対応
