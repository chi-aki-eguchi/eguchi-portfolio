写真とコメントを、
ひと組で受け取る。

ファイル名の手入力を減らしたい場合は、写真セレクト便で候補を渡せます。相手が選んだ写真とコメントが、元のファイル名に対応して戻ります。

選ぶ → 受け取る、を体験する製品の内容・価格

送る前の確認

  • 候補数と最終採用数を区別して書いた
  • 期限に日付と時刻を入れた
  • 元のファイル名を残して渡している
  • 相手が開ける方法・閲覧権限になっている
  • 返送先と、完了の連絡方法を書いた

スマートフォンだけの相手には、共有リンクの方法を検討してください。

写真セレクトの依頼で、迷いやすいこと

候補を何枚選んでもらえばいい？

使用する枠が決まっているなら、その枠ごとの候補数を伝えます。「表紙候補2枚・本文候補5枚」のように用途を分けると、縦横や役割が揃います。選択数がそのまま最終納品数なのかも書いてください。

メールで写真を選んでもらうには？

確認画像と元のファイル名を対応させ、返信時もファイル名を使ってもらいます。写真セレクト便のHTMLを添付できない場合はZIPにまとめ、相手と合意した方法で共有します。社内規則でHTMLを開けない場合はファイル名返信や共有リンクを選びます。

この依頼文は有料版を買わなくても使える？

はい。作成した文章は、そのままご自身の案件に使えます。ファイル名返信・共有リンクの文面は、写真セレクト便を使わない場合にも利用できます。
