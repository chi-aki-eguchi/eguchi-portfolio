## 最初の販売目標と振り返り

目標は公開後30日で、内容が合う無料相談3件・有料制作1件。これは計画であり、実績や保証ではない。

公開設定30,000円、写真・文章編集付き69,800円の既存プランを案内する。継続実費・範囲・日程は相談で合意し、注文を伴わない無料相談を入口にする。最初の実績づくりを理由に、未承認の値引き・無料制作・広告費支出はしない。

1. Google の表示回数・検索語・ガイドへのクリックを確認する。表示がなければ登録状況とリンクを確認する。
2. 訪問はあるが相談がない場合、料金・対応範囲・管理画面の説明で分かりづらい点を改善する。
3. 相談が来たら、用途・素材・希望日を確認し、見積もりと条件に合意した場合のみ制作へ進む。
4. 納品後、本人の許可を得て掲載できる事例と感想を増やす。作者自身の akieguchi.com は作者の運用例と明記し、顧客事例として扱わない。
