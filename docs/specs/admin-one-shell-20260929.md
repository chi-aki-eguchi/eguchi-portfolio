# 管理画面を骨格に関係なく1つにする（2026-09-29）

> 同日、「サイト」の目次（下の 2・3・6・7）は `admin-site-editor-20260929.md` の「見ながら直す画面」に置き換えた。器（1・5・8〜10）と節の分け方（4）はそのまま。

## 依頼

オーナー: 「アドミンがすごいわかりづらい。何がどこにあるのか、何が変えれるのかが複雑。サイトの骨格を変えたらアドミンも全部変わっちゃって、よくわからない」。

## 実物で確かめた原因

- 管理画面が2つあった。`siteDesign`（サイトの骨格）が `book`（写真中心）なら上に3つの入口の明るい画面、`classic`（いつもの構成）なら左の縦メニューの黒い画面に、画面ごと入れ替わっていた（`admin.tsx` の分岐）。言葉も「すべての写真／写真一覧」「写真を加える／取り込む」「サイト／サイト編集」と別々。
- 2026-09-29 の本番は `siteDesign = classic` だった（公開 `/api/settings`）。写真中心の管理画面に慣れたところで骨格を戻し、別の管理画面に切り替わった状態。
- 写真中心の「サイト」では、「サイトの骨格」1項目の中に骨格・トップの形・About・Contact・Series の札・切り抜き・ビューアの壁と大きさ・作家の言葉・見出し・フッターの11個が詰まっていた。いつもの構成でしか効かない6節は目次から消え、骨格を戻すと出てくる。

## 決めたこと

1. 管理画面はいつも「写真・シリーズ・サイト」の器（`BookAdminShell`）。骨格は公開サイトだけを変える。左の縦メニュー・スマホの下部バー・折りたたみレールは削除。
2. 「サイト」の目次の正本を `admin-settings-navigation.tsx` の `SITE_OUTLINE` 1つにした。公開サイトのどこが変わるかの順（サイト全体／トップ／写真とシリーズ／About・Contact／見た目／そのほか）で、各項目に効く場所を一言添える。設定画面の中の検索・見出しも同じ台帳から作る。
3. 片方の骨格でしか使わない項目は隠さない。目次と項目名に「写真中心のとき」「いつもの構成のとき」の札を付け、今の骨格で使わなければ薄くする。節の先頭に「今は使われていない・値は残る」と一言。骨格を切り替えても目次は動かない。
4. 詰め込まれた節を分けた: `page-layout`（骨格だけ）／`home`（トップの形・作家の言葉）／`viewer`（写真を開いたとき）／`page-parts`（About・Contact の組み方）／`page-frame`（見出しとフッター）。Series の札と切り抜きは、いつもの構成だけで効くので `gallery-layout` へ。節は 21 → 25。設定キーと保存値は変えていない。
5. いつもの構成の管理画面にしか無かった画面も同じ器から開ける: トップの写真と順番（HERO）、シリーズの詳しい設定（シリーズごとの配色・並び順の上書き）、写真の詳しい道具（従来の写真一覧）。未セットアップのときは「はじめに」を開く動作も引き継いだ。
6. スマホの「サイト」は目次と中身を1画面ずつ。「サイト」を押すと目次、項目を開くと（目次・探す・画面の中の案内・最初のセットアップから）中身だけになり、「← サイトの一覧」で戻る。PC 幅で開いた画面は、幅を狭めても作業中の項目を出したまま。設定の中の「設定項目」一覧（目次と重なる2つ目の一覧）は出さない。
7. 目次の上に「設定を探す」を置いた（項目名・一言・関連語で絞る。Enter で最初の項目を開く）。スマホの「探す」は下の「メニュー」の中。
8. 設定の節どうしの移動では「保存せず移動しますか」を出さない。下書きは節をまたいで1つで、変更のある節には目次に印が付き、1回の保存でまとめて送る。写真・シリーズ・ほかの編集画面へ移るときは従来どおり確かめる。
9. スマホの上の帯は2行（名前と「メニュー」／入口3つ）。PDF作品集・探す・暗い表示・サイトを見る・JP/EN・ログアウトは「メニュー」の中。道具を並べたままだと 320px 幅で帯が5行になり、写真の編集欄が 77px まで潰れていた。PC は今までどおり右に並べる。
10. いつもの構成の管理画面にあった言葉の切り替え（JP / EN）を、器の道具の右端に置いた（体験版は上の帯のまま）。

## 残したこと・未対応

- 管理画面の英語表示: 入口・写真・シリーズの画面は日本語のまま（写真中心では以前から同じ）。設定の中身と編集画面は英語に切り替わる。
- `admin-surface`（管理画面の明暗の3択）と `useAdminSurface` は、今の器では使われていない。明暗は上の「暗い表示」で切り替える。整理は別作業。

## 検証

- 単体・描画テスト: 骨格を切り替えても入口と目次の項目が同じで、使わない項目だけ薄くなる（`admin-book.render.test.tsx`）。目次が全節をちょうど1回ずつ含む（`admin-settings-section-keys.test.ts`）。
- smoke: `admin-one-shell.spec.ts`（PC で目次の一致・薄い項目の案内、スマホで目次⇄中身の切替と 44px）。旧い左メニューを前提にした spec は、新しい器での同じ目的へ書き換えた（左ナビ・下部タブバー・折りたたみレールだけを見ていた3本は削除）。以前のタブ名で開く共通の読み替えは `scripts/smoke/helpers.ts` の `storeAdminTab`・`revealAdminPanel`。
- 実画面: 手元の隔離サーバー（`bun run try:admin`、人工データ）で PC 1440 とスマホ 390 を両方の骨格で撮影。
