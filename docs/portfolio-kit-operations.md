# Portfolio Kit 購入対応の手順

対象: Portfolio Kit の購入通知を受け取り、購入者へ最初の案内を送る秋さん。

プランは「公開おまかせ」（¥30,000）のみ（2026-07-18 一本化）。
購入が入ったら、**24時間以内に素材のお願いをメールで送り、素材が揃ってから3日以内に納品**します。
設置リンク（Railway テンプレート）はオーナー専用の設置ツールになったため、購入者には渡しません。

用語メモ:

- Stripe: クレジットカード決済と購入通知を管理するサービス。
- リダイレクト先: 支払いが終わったあと、自動で購入者に表示するページ。
- Railway: Portfolio Kit のサイトをインターネット上に設置して公開するサービス。
- 引き渡しカード: 購入者が公開後に使う入口だけを5項目にまとめた案内。

## 最初に1回だけ確認すること

Stripe ダッシュボードを開き、「公開おまかせ」（¥30,000）の Payment Link で確認します。
設定画面の名前は Stripe の更新で少し変わることがあります。

- [ ] 旧「自分で立てる」（¥10,000）の Payment Link を無効化（アーカイブ）した
- [ ] 秋さんのアカウントで、支払い成功の通知メールが有効になっている
- [ ] 支払い完了後のリダイレクト先が `https://akieguchi.com/portfolio-kit/start` になっている
- [ ] 決済完了画面のカスタムメッセージに purchase-thankyou.md の文面を入れた
- [ ] 購入者へ領収書メールを自動送信する設定が有効になっている
- [ ] 決済画面で購入者のメールアドレスを収集する設定が有効になっている
- [ ] 決済リンクをテスト表示し、購入者のメールアドレス欄があることを確認した

確認後は、この手順書に確認日をメモしておきます。

- 確認日: 2026-07-16（通知メール・リダイレクト先・領収書メールの3点をオーナー確認済み。
  2プラン時代の確認。単一プラン化後の再確認はこれから）

## 通知を見落とさないための予備確認

販売開始後は、通知メールの有無にかかわらず、**1日1回** Stripe ダッシュボードの支払い一覧を確認します。
新しい支払いがあれば、下の購入記録と照らし合わせ、未記録・未送信の購入がないか確認します。

## 購入記録の雛形

購入ごとに1行追加します。購入者の情報を含むため、公開リポジトリには保存せず、オーナーだけが見られる安全な場所で管理します。

| 日付 | 購入者 | 素材依頼送付 | 素材受領 | 納品日 | メモ |
| --- | --- | --- | --- | --- | --- |
| YYYY-MM-DD | 氏名または管理用の識別名 | YYYY-MM-DD HH:mm | YYYY-MM-DD | YYYY-MM-DD | 連絡状況など |

## 購入通知が届いたら

1. Stripe の入金通知メールを開く。
2. Stripe ダッシュボードで該当する支払いを開き、`成功` または `支払い済み` になっていることを確認する。
3. 購入者の名前、メールアドレス、支払日時を確認する。
4. **支払日時から24時間以内**に、下の文面（素材のお願い）を送る。
5. 送信済みであることと送信日時を、購入記録に残す。

通知メールだけで判断できない場合は、必ず Stripe ダッシュボードの支払い状態を確認します。
支払いが未完了・返金済み・不明な場合は、作業を始めずに確認を優先します。

## 設置から納品まで

購入者の素材が揃ったら、次の順で進め、**素材が揃ってから3日以内**に納品します。
設置リンク（Railway テンプレート）はここでオーナーだけが使います。

- [ ] 設置リンクから購入者用の Railway プロジェクトを立て、公開URLが開くことを確認する
- [ ] 独自ドメインを使う場合: 画面共有（30分目安）で購入者名義のドメインを一緒に取得し、接続する
- [ ] サイト名、プロフィール、連絡先、SNS、管理画面用パスワードを初期設定する
- [ ] 最初の写真を投入し、トップと作品一覧で表示を確認する
- [ ] 購入者自身が管理画面へログインできることを確認する
- [ ] 次の「引き渡しカード」5項目を、1通のメールにまとめて渡す

引き渡しカードの5項目は、`/portfolio-kit/start` の HANDOFF CARD と同じ内容です。

1. あなたのサイトURL
2. 管理画面URL
3. 管理パスワード
4. 最初に入れる写真
5. 困った時の連絡先

管理パスワードはメール本文へ直接書かず、できれば別の安全な方法で渡します。
メールで渡す場合は、サイトURLや管理画面URLとは別のメールに分けます。

## 納品後の相談範囲

- 操作方法の相談は当面、期間・回数の制限なし（2026-07-16 オーナー決定。将来、期間制へ変更する可能性があるため、販売文では必ず「当面は」を添える）。
- デザイン変更・個別カスタム・作業の代行は、内容に応じて別途お見積もりします。

## 困ったときの一次対応

購入者は Railway を操作しません。技術的な調査はすべてオーナー側で行います。

1. 購入者には「何が起きたか」と、可能なら画面のスクリーンショットだけをもらう
   （パスワードは映さないよう伝える）。
2. オーナーが該当プロジェクトの Railway ダッシュボードを開き、Logs（動作記録）と
   Variables（設定項目）を確認する。
3. 購入者の写真、設定、Railway のサービスを削除せず、状況を記録してから保守担当へ相談する。
