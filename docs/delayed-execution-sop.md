# 後で実行する作業

時間を指定されたときだけ参照する。作業方針・検証・push可否は [AGENTS.md](../AGENTS.md) と同じで、予約専用の禁止規則を追加しない。

- 対象の作業、日時とタイムゾーン、単発か繰り返しか、完了条件を明確にする。
- その環境で利用可能な予約機能を使い、登録結果を確認する。未登録の計画を予約済みと報告しない。
- 発火時は `task.md` とGitの実状態を確認し、予約後に進んだ作業を巻き戻さない。
- 実行結果・検証・残件を記録する。既に許可された公開を「予約だから本人しかできない」と扱わない。

旧ツールの機能・推奨は [2026-06の記録](archive/delayed-execution-sop-2026-06.md) に保存した。当時のコマンドや制約を現行の指示として使わない。
