QUESTIONS

よくある質問

写真はどこかに送信されますか？

このツールから写真・案件・回答を外部サーバーへ送信することはありません。閲覧用HTMLには小さな確認画像が埋め込まれるので、そのファイルを渡す相手は慎重に選んでください。配布ページへのアクセス記録と、ツール内の写真処理は別です。

RAWやHEICを読み込めますか？

対応していません。写真編集ソフトからJPEGを書き出して使ってください。確認用の画像なので、色校正や最終納品には使わず、選択後は原本から仕上げてください。

選択結果は自動で届きますか？

依頼主が「回答ファイルを保存」し、撮影者に返送する必要があります。保存しただけでは送信されません。回答ファイルには写真を含めません。

写真のコピーや転送を防げますか？

完全には防げません。透かし文字を入れられますが、閲覧期限、パスワード、転送禁止を技術的に強制する機能はありません。

途中の案件を再開できますか？

撮影者は「案件ファイルを保存」で控えを残し、次回読み込みます。依頼主は回答ファイルから再開できます。ブラウザ内の途中保存だけに頼らず、ファイルも保存してください。

Adobe製品への自動取り込みはありますか？

ありません。ファイル名一覧、拡張子を除いた一覧、コメント付きCSVを使って、元の写真と照合できます。特定の写真編集ソフトとの連携を保証する商品ではありません。
