# 企画書 #03 — ソーシャル成長 & サイトのリーチ拡大（X / Instagram / note）

状態: **提案（戦略・運用中心 / 一部は将来コード提案）** ／ 起案 2026-06-14

## 0. 基本設計：3つのSNSとサイトの役割分担
- **Instagram** = 発見エンジン（新規が写真に出会う入口）
- **X** = 拡散と人柄（写真＋制作の裏側、リアルタイム会話）
- **note** = 物語と信頼（長文・シリーズの背景・SEO資産。サイトに RSS 連携済み）
- **サイト(akieguchi.com)** = ハブ（全部を束ね、依頼に変換する“家”）
原則：**SNSは入口、サイトは目的地、依頼が出口。** 全導線をサイトの /contact に集約する。

## 1. Instagram（新規発見の主戦場）
- **グリッドの一貫性**：投稿単位でなく「9枚で見たときの面」を整える＝写真集の表紙感（design-spec と同じ思想）。
- **フォーマット使い分け**：
  - カルーセル（複数枚）= シリーズの抜粋。最後の1枚を「続きはサイトで」誘導に。
  - リール = 制作過程・撮影の空気。発見タブ流入はリールが最大。
  - ストーリーズ = 新シリーズ公開時にサイトの該当 /series へリンク。
- **alt と説明**：被写体・場所・機材を1〜2行。IG内検索とアクセシビリティ両取り。
- **プロフィールの link in bio = akieguchi.com**（現状の sameAs と整合）。1リンクなら /gallery か新シリーズ。
- **頻度より一貫性**：週2〜3でも“同じ眼”が伝わるリズムを優先。

## 2. X（拡散と人柄）
- **写真スレッド**：1テーマ4〜6枚を連投＋短い言葉。RT されやすい。
- **制作の裏側**：機材・現像・ロケの話は同業/愛好家に刺さりフォロー転換が高い。
- **会話に参加**：写真コミュニティ/ハッシュタグの会話に反応。一方通行にしない。
- **サイト誘導**：スレッドの最後に該当シリーズURL（OGP は per-page 実装済みでカード映えする）。

## 3. note（物語・信頼・SEO資産）
- **強み**：note ドメインの検索強度＋長文で「人となり」が伝わる。**サイトに RSS 表示済み**なので書くほどサイトも厚くなる。
- **コンテンツ**：各シリーズの制作記、撮影地の話、機材レビュー、依頼の流れ紹介。
- **SEO相乗**：note記事 →（本文末で）サイトの該当シリーズへ相互リンク。サイト→note も Journal 経由で双方向。
- **将来の有料note**：制作裏話/現像セッティングを有料マガジン化（#04 マネタイズで詳述）。

## 4. サイト↔SNS の相互増幅（ハブ設計）
既にある：sameAs(IG/X/note)・note RSS・per-page OGP・画像サイトマップ213・GA4。
追加で効くこと：
- **各シリーズを“共有したくなる”単位に**：OGP は出来ているので、シリーズに statement（#02/序文）を足すと共有時の説得力が増す。
- **（将来コード提案）共有ボタン or 「このシリーズをシェア」** を series-detail に控えめに設置。
- **（将来コード提案）メール購読（newsletter）取得**：SNSはアルゴリズム依存。自前リストは最強の再訪資産。最小実装は「新作公開を知らせる」登録1フィールド。
- **名前で見つかる**：Google で「江口 秋 写真」等で出るよう、Person JSON-LD（実装済 sameAs）＋ Search Console 登録（#A）。

## 5. リーチを増やす“サイト側”の施策（SEO/発見）
- **Search Console 登録＋sitemap送信**（最優先・#A）→ 画像213件が Google画像検索の入口に。写真家の実需流入。
- **画像SEO（alt運用）**：per-photo alt を被写体/場所で（#B・別企画化候補）。画像検索はIG外で最大の発見経路。
- **ページ速度**：LCP preload 済み・コード分割済みで土台は良好。維持。
- **被リンク**：撮影先・コラボ相手・掲載媒体からのリンクを依頼（地味だが効く）。

## 6. 30日の実行イメージ（運用・コード不要）
- 週1 note（シリーズ制作記）→ 末尾にサイト相互リンク。
- 週2〜3 IG（カルーセル/リール）→ link in bio = サイト。
- X は note/IG 公開時に写真スレッドで告知。
- 月初に GA4 で「どのシリーズが見られたか」を確認 → 次月の投稿テーマに反映。
