# 「サイト」を見ながら直す画面（2026-09-29）

`admin-one-shell-20260929.md`（管理画面を骨格に関係なく1つに）の続き。そちらの「サイトの目次（`SITE_OUTLINE`）」は、この画面に置き換えた。

## 依頼

オーナー: 1つ目の作り直しを見て「あんまり変わってなくない？もっと使いやすくできるでしょ」「多分全部？わかりづらいしださい」。選んだ方向は「サイトを見ながら直す」。

- 公開サイトを大きく出す。上でページ（トップ／Gallery／Series／About／Contact）を選ぶ。
- 変えられる所に枠が出て、押すとその部分の設定だけが横に出る。
- 長い目次はやめる。「全体の見た目」「そのほか」を並べる。

## 画面

```
┌ 写真 シリーズ サイト ─────────────────────── 探す・サイトを見る… ┐
├ トップ Gallery Series About Contact ──── 🎨全体の見た目  ⚙そのほか ┤
│                                         │ 設定を探す             │
│   公開サイトのプレビュー（主役）          │ トップで変えられるところ │
│   ・乗ると押せる所に薄い点線              │  T  名前               │
│   ・部分に乗ると「名前を変える」の札       │  🖼 トップの写真         │
│   ・押すと右にその設定だけ               │  ❝  作家の言葉          │
│                                         │  ✉  撮影のご依頼        │
│   ( PC幅 | スマホ幅 · ↶ ↷ · ↻ 公開サイト↗ )│  ☰  メニュー ／ ▭ フッター│
└─────────────────────────────────────────┴───────────────────────┘
```

- 右の欄はページにある部分だけ（`SITE_PAGES` の `parts`）。行には形の目印（アイコン）と一言。行に乗ると、プレビューのその部分に枠が付く。
- 部分を開くと「← トップ」・部分の名前・一言・関係する画面への入口、その下に設定。設定は「もの」ごとの節（名前なら表示する文字・大きさ・太さ・字間・色が1か所）。
- 「全体の見た目」: 書体・本文とリンク・見出し・色と背景・サイトの骨格（いつもの構成では デザインの出発点・余白・表示アニメーションも）。「そのほか」: 連絡先と検索・表示する言葉・トップの写真と順番・シリーズの詳しい設定・分類・料金・制作案内・カメラの候補・note・プリント販売・はじめに。
- 「設定を探す」はすべての部分と25節から探す。今の骨格の一覧に無い節も、探せば開けて「今は使われていない・値は残る」と一言添える。
- プレビューの操作は下に浮かぶ1本の帯だけ: PC幅／スマホ幅・元に戻す／やり直す・読み込み直し・公開サイト。上の帯（寸法の数値入力・大きく表示）と下の帯（編集中／保存済みの切り替え・倍率）はやめた。見ながら直す画面のプレビューはいつも編集中の内容を映す。
- Series を開いているときだけ、帯で作品ごとのページ（`/series/…`・`/work/…`）も選べる（2026-09-17 の「作品を直接選ぶ」を残す）。別のページへ移ると一覧へ戻る。
- スマホ: 上の帯（ページと全体の見た目・そのほか）は1本で横に送る。「編集／プレビュー」の丸い切り替え。初めて開いたときのプレビューはスマホ幅。プレビューで部分を押すと編集へ切り替わってその設定が出る。帯は画面の幅に収め、元に戻す・やり直すは編集の側。

## 実装の地図

- 台帳: `pages/admin-settings-navigation.tsx` の `SITE_PARTS`（部分 → 節・骨格ごとの節・別画面・関係する画面）、`SITE_PAGES`、`SITE_LOOK_PARTS`、`SITE_MORE_PARTS`、`partIsListed`。節の名前と関連語は `SETTINGS_NAVIGATION`。
- 画面: `components/site-editor/`（上の帯・右の一覧・部分の見出し・器）。状態は `admin.tsx`（`admin:site:page` / `admin:site:mode` / `admin:site:part`、体験版は `:demo` 付き）。
- 設定: `SettingsTab` の `visual`（プレビューを常に出す・右の欄に1節・押せる部分の一覧）。プレビューの帯は `AdminSettingsPreviewPane` の `compact`。
- プレビューの中を押せるようにする: `lib/admin-preview-pick.ts`。公開サイトの class 名 → 部分の対応（`PREVIEW_PART_SELECTORS`）。公開サイトの class を変えたらここも直す。

## 残したこと

- プレビューで見つからない部分がある: 写真を開いたとき（画面に常には出ない）、About・Contact の組み方（同じ所は文章・連絡先が先に取る）、フォームの言葉（送信先が無いとフォームが出ない）。どれも右の一覧からは開ける。
- 寸法の数値入力・大きく表示・保存済みとの比較は、見ながら直す画面から外した。
