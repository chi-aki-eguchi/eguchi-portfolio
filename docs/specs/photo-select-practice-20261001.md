# 写真セレクト便 v1.1.1と受け渡し練習 — 2026-10-01

購入前にファイルの受け渡しまで試せるよう、公開作品6枚を含む練習用HTMLを追加。HTMLを保存→選択して回答JSONを保存→無料版の空の画面から両ファイルを読む→CSVで照合する。返送は本人が普段の共有方法で行う。自動返送の機能として説明しない。

依頼文作成では直接編集した文章が、条件変更で消える問題を修正。手直しを保持し、利用者が明示して作り直す。作り直した直後は以前の文章へ戻せる。写真や入力内容を外部へ送信・計測しない。

紹介ページの先頭は写真・元ファイル名・仕上げコメントの回答例を組にして示す。実利用の推薦・顧客実績には見せず、説明例であることを明記する。SNSは使用しない。
