依頼: 「細かい文字の統一感、レイアウト、高級感、UIの完成度」「サイト全体のAIが作ったような感じをなくしたい」。前担当の評価を採用せず、本番と現行Admin（book / Studio）・体験版を実画面で照合してから変更した。

## 方針

- 写真の並べ方・元比率・表示設定は変えない。本番の設定値（書体・大きさ・見出しの型）にも触らない。
- 文字は役割で分ける。読む文は濃く（0.84）、補足・ラベルは12px以上・大文字にしない。和文を含む期間は和文書体で。
- 作品の後ろの依頼・制作案内は1行にし、作品と同じ強さにしない。
- 制作案内は日英同じ構成。見出しはサイトの和文書体、本文・料金・操作はゴシック体。節ごとに中身に合う形（画面を大きく／役割を並べる／料金を比べる／手順を順に／質問を開く）。
- Adminは操作の速さと読みやすさを優先。公開サイトと同じ黒と灰で、青はドラッグ先の合図だけに残す。

## 変更

| 画面 | 変更 |
|---|---|
| TOP | 3枠 → 目次の2行（Gallery すべての写真 354枚 ／ Series シリーズで見る 4組）。数は公開中の写真・シリーズ・仕事から数える。依頼は1行（題・文・お問い合わせ） |
| Gallery / Series / シリーズ詳細 | 末尾の依頼を同じ1行に。シリーズ詳細では「次のシリーズ」の後に置く |
| フッター（オーナーのサイト） | 制作案内を1行（「このサイトと同じ仕組みで…」＋リンク＋写真セレクト便）。SNS・規約は1行に並べ、©を下に。オーナーのサイトではテンプレート表記を出さない（制作案内と同じ行き先）。配布先は従来どおり |
| About | 略歴15px・濃さ0.84、Journalの日付・題・抜粋の大きさと濃さを整理、小見出しを通常の大小文字に |
| Contact | 「対応地域」「撮影までの流れ」の和文ラベル、案内文と撮影相談の行間・濃さ |
| Series | 期間を和文書体・等幅数字・12px以上に |
| TOPの名前 | 英名と肩書きを同じ基準線に |
| 制作案内（日英） | `PortfolioSalesPage` を日英共通に。肩書き・標語の帯・パンくずを削除、頁内の移動は右上の1行。見本の切替はシリーズから（トップは冒頭に出しているため）。受け取るもの・役割分担・料金2列・手順1列・質問・相談を1列の読む順に。料金は2本の罫線で比べ、価格を最も大きく。料金の文言・条件は変更なし。重複していた「江口秋が担当」は冒頭だけ |
| ガイド・相談・開始手順 | 本文をゴシック体、見出しをサイトの和文書体に。英字の肩書きを削除、見出しを具体的な言葉へ（「納品後に分からないとき」「納品時にお渡しするもの」） |
| 管理画面の紹介 | 大文字の「実際の管理画面から」を削除、切替名を短く（写真の入れ替え／見せ方の変更／文章の更新）してスマホで1行に |
| 現行Admin | 検索欄「題・ファイル名・カメラで探す」（詳しい書き方は title）、スマホでは1行幅。チェックは黒。サイト目次を「制作案内のページ」「制作案内への入口」 |
| 体験版 | 帯を上の帯の直前に置き空白を解消。案内は番号・罫線・黒いボタンで現行Adminと同じ色に |

写真・文章の削除はしていない。削除したのは装飾（英字の肩書き・標語の帯・テンプレート表記の重複・番号の飾り）と、同じ意味の繰り返し1文。
