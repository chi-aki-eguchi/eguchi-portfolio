  Claude CodeがReviewer（読み取り専用）を担当。

### 調査結果

- 対象は公開Galleryではなく、`/admin` のLibrary。
- Chromiumのデスクトップ相当で高速ホイール操作を計測すると、読込待ち画像が
  最大20枚見える状態と、ポインター直下のカードの浮き上がり・影を再現できた。
- Chromiumのタッチ端末相当では、6往復の高速スワイプ中に逆方向ジャンプは
  再現しなかった。実機での申告を否定せず、仮想グリッドのスペーサー交換時に
  ブラウザがscrollTopを補正しない予防策を追加した。

### 変更内容

- Libraryの現在位置より前後8行分のサムネイルを先読みし、高速移動先の読込を
  早めた。画面上のタイル数は引き続き仮想化で抑えている。
- 未読込画像は白く露出させず、既存の紙色の台紙から短くフェード表示する。
- デスクトップの高速スクロール中はタイトル・移動ボタン等のhover表示を一時停止する。
  スマホで常時表示する操作ボタンは隠さない。
  写真カード自体のhover浮き上がり・影・押下縮小は、ちらつき原因のため廃止。
- Libraryスクロール領域を`overflow-anchor: none`にし、仮想グリッドの上下
  スペーサー差替えでブラウザが逆向き補正しないようにした。
- スマホLibraryに「2列 / 3列」切替を追加。選択列数からタイル幅を計算し、
  375px/390px幅の両方で3列表示できることをブラウザテストで確認した。3列は
  写真一覧を優先して並べ替えボタンを隠し、2列へ戻すと並べ替えできる。
- 高速スワイプの白抜け、カード変形、影、hover表示、逆方向ジャンプを測る
  回帰テストを新設し、既存のスマホLibraryテストを列数切替まで拡張した。
