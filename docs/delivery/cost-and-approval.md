内部単価の**仮定**3,000円/時の場合、初期工数4/8/12時間は12,000/24,000/36,000円。ここにインフラ実費・取引費用を差し引く。69,800円で8時間なら残額45,800円は「決済費用・初期実費控除前」であり会計利益ではない。実工数が無いので黒字とは断定しない。

推奨: 最初の1件は現行2プランを維持し、基本プランの登録枚数・ページ・修正・納期を見積ごとに限定する。標準案の30枚／3シリーズ／修正1回は未承認。代案は編集付き69,800円だけで初回受注を絞る。どちらも継続インフラ実費・操作相談の現行約束・保守範囲を事前に書面化する。

## 一度に確認する未承認事項

1. 顧客クラウド: 顧客名義のRailway＋PG＋非公開Storageを推奨。新規課金・プラン・上限・バックアップ保存先・ドメインを、実際の対象顧客が決まってから承認。現在はローカルのみ。
2. 商品条件: 現行価格維持、基本プランの初期登録量・納期・修正範囲、継続保守と操作相談の責任。既存の当面無制限相談を30日へ無断変更しない。
3. 契約: 正式な事業者情報・税扱い・キャンセル・解約・バックアップ保持・移管。未記入は本番掲載せず、条件確認書で提示・訂正・合意を残す。
4. 公開: 今回ブランチの表示統一・新規顧客向け非公開初期設定を本番へ統合する対象。main pushは個人サイトへの反映になる。
5. 人の確認: 実機でログイン・写真追加・並べ替え・プロフィール保存・問い合わせ受信、購入者による操作確認。PDFの紙の確認と実決済は別。

法的適合を認定しない。公式ガイドの最終確認画面の条件・訂正可能性、広告で必要な事業者・対価・提供時期等を実際の申込方式に当てはめて確定する。手動相談→条件合意→決済でも、支払リンクへ進む前に必要な条件を示す。

- https://www.no-trouble.caa.go.jp/what/mailorder/guidelines.html
- https://www.no-trouble.caa.go.jp/qa/advertising.html

技術試験が成功しても、契約未確定のまま新しい「保守込み」商品として受注開始しない。既存契約の有無は不明で、ゼロと扱わない。

## プログラム・素材・書体の受渡し

今回の直接production依存の実インストール版とlicense表記は `dependency-licenses.json`。MIT / Apache-2.0 / ISC / Unlicense等に加え、既存のPM2にAGPL-3.0表記がある。今回のローカルBun起動はPM2を使わず、納品source.tarにもnode_modulesは含めない。推移依存や商用再配布全体への適合認定はしていない。顧客へバイナリ・依存コードを含めて渡す場合は、該当noticeと必要なソースを揃える。

NotoフォントのOFLは `packages/web/assets/fonts/OFL.txt` と `public/fonts/pdf/OFL.txt` をソースに保持。見本の写真の出典・権利表示は `sample-sources.json`。アプリ本体には独立したLICENSEファイルが無いため、顧客へ認める利用・改変・移管・再配布の範囲を条件確認書でオーナーが確定する。公開リポジトリという理由で顧客に無制限の再販権を付けない。
