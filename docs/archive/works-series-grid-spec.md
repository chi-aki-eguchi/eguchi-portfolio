## 参考サイトから取り入れる本質

濵田サイトのWorksは「**写真1枚**」ではなく「**シリーズ（作品単位）の代表写真**」がグリッドに大量に並ぶ。タイルをクリックすると、そのシリーズの詳細ページで中の写真が大きく綺麗に見られる。

秋の評価：「グリッドで大量に見えて、気になるのをクリックしたらシリーズが拡大されて綺麗に見えるのが良い。ただしタイルが小さすぎる。システムは良い」

→ この構造を秋のサイトに応用する。ただしタイルは濵田より**大きめ**にする。

## グループP: シリーズグリッド（Works構造の刷新）

### P1. 写真一覧とシリーズ一覧の両方を持つ【確定】

秋の意向：写真一覧（今のギャラリー）とシリーズ一覧の両方を残す。

- **写真一覧（既存ギャラリー）**: 全写真が1枚ずつ並ぶ。現状維持。
- **シリーズ一覧（新・濵田風）**: シリーズの代表写真がグリッドで並び、クリックで詳細へ。
- ナビゲーションまたはWorksページ内のタブで両者を切り替えられるようにする。
  - 例: Works ページ上部に「Photos / Series」の切り替え。
  - または ナビに「Gallery（写真）」と「Series（シリーズ）」を別項目で置く。
  - **どちらの導線にするかは実装時に両方試して、自然な方を採用**（秋がプレビューで確認）。

### P2. シリーズグリッドの仕様【確定】

- **タイル = シリーズの代表（表紙）写真のみ**。作品名・年などの文字は出さない（写真だけ・ミニマル）。
- **Grid表示のみ**（List表示は作らない）。
- タイルをクリック → そのシリーズの詳細ページ（`/series/:slug`、既存）へ。
- 詳細ページでは中の写真が大きく綺麗に並ぶ（既存のPhotoGallery・レイアウト選択が活きる）。

### P3. タイルのサイズ感【確定・重要】

濵田サイトは秋にとって「小さすぎる」。なので：
- タイルを**大きめ**にする。PCで2〜3列（濵田は4〜5列相当で小さい）。
- 列数を Settings から調整可能にする（新規キー `seriesGridColumns`、既定 3、範囲 2〜4）。
- スマホは1〜2列（`seriesGridColumnsMobile`、既定 2、範囲 1〜2）。
- タイル間の余白も調整可能（既存の galleryGapScale を流用 or 専用キー）。

### P4. ホバー時の挙動【確定】
- タイルにホバーで軽く反応（わずかな拡大 or 明度変化）。作品名は出さない方針なので、ホバーでも文字は出さず、視覚的フィードバックのみ。
- design-spec の「静かなUI」に合わせ、過剰なアニメーションは避ける。

### P5. 代表写真の選び方【確定】
- シリーズの `coverPhotoId`（既存）を代表写真として使う。
- 未設定の場合はそのシリーズの先頭写真を自動で使う。
- 管理画面のシリーズ編集で表紙を選べる（既存機能）。

### P6. カテゴリでの絞り込み【任意・実装時判断】
- 濵田はWorksをカテゴリ（advertisement/editorial/portrait等）で絞れる。
- 秋のシリーズにカテゴリの概念を持たせるかは要検討。
  - シリーズ自体にカテゴリを付けるなら schema 変更（series に category 追加）。
  - 今は写真にカテゴリがある。シリーズ単位のフィルターが欲しいか実装時に秋へ確認。
- **初期実装では絞り込みなしでよい**。シリーズ数が増えてから検討。

### P7. データモデル
```
# siteSettings 追加
seriesGridColumns        # PC列数（既定3、範囲2〜4）
seriesGridColumnsMobile  # スマホ列数（既定2、範囲1〜2）
worksDefaultView         # Worksで最初に見せるもの "photos" | "series"（既定はどちらか実装時決定）
```
- 新規スキーマ変更は基本不要（シリーズ機能は既存）。P6でカテゴリを付ける場合のみ series テーブルに追加。

### P8. 受け入れ基準
- [ ] シリーズの代表写真がグリッドで並び、クリックで詳細ページに飛ぶ
- [ ] タイルは写真のみ（文字なし）、Grid表示のみ
- [ ] タイルが濵田より大きめで、列数を管理画面から調整できる
- [ ] 写真一覧（既存ギャラリー）とシリーズ一覧の両方が見られる
- [ ] スマホでタイルが窮屈にならない
- [ ] 代表写真未設定のシリーズは先頭写真が自動で使われる
- [ ] ホバーで静かな視覚フィードバックがある（文字は出さない）

## 実装の進め方

1. シリーズグリッドのコンポーネントを作る（タイル=表紙写真、クリックで /series/:slug）
2. Works の導線（Photos/Series 切り替え or ナビ分割）を両方試し自然な方を採用
3. タイルサイズ・列数の調整UIを Settings に追加（ライブプレビュー連携）
4. ホバー挙動を design-spec に合わせて調整
5. PC/スマホ両方で確認
6. 余力で P6（カテゴリ絞り込み）を検討

> 既存のシリーズ機能（series テーブル・/series・/series/:slug・表紙選択）をフル活用する。新規の重い実装は不要で、主に「見せ方」の追加。
