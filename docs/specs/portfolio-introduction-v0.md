# 仕事・作品の紹介ページ 初期版

確認日: 2026-10-05。対象は、今回の相手が使える Portfolio Kit。職種・掲載したい実績は未確認のため、写真の仕事には限定しない。

## できること

シリーズまたは Work の「ページの見せ方」で、従来の写真表示と「紹介ページ」を選ぶ。紹介ページでは、文章（見出しと本文）、画像、外部リンク、制作情報（任意の項目名と内容）を追加し、上下に並べ替えられる。写真が0枚でも文章のある公開実績を一覧に表示する。

初期状態は従来の写真表示。紹介ページに切り替えた実績だけが新しい表示になる。写真と紹介本文は独立して保持し、写真表示へ戻しても本文を消さない。本文の変更は「紹介ページを保存」で確定する。

新規作成で「紹介ページとして作る」を選んだ場合は非公開で開始する。本文保存とシリーズの公開・非公開は別操作。「紹介本文のプレビュー」で本文を確認できる。

## 試す

- 公開体験版: `/admin/demo?intro=1`。既存の所有者サイト限定の体験版と同じ公開条件。架空の画像入り／文章のみの2例をブラウザー内に追加し、最初から紹介ページの編集を開く。実DBへ書き込まない。
- 手元: `bun run try:intro` → `http://localhost:5599/admin/demo?intro=1`。専用の一時SQLite、人工写真、127.0.0.1の偽ストレージを使う。終了時に一時データを消す。
- 保存後、シリーズ上部の「サイトで見る」で仕上がりを確認する。体験版は別窓でも同じ見本を読む。

## 保存と公開

- `series.content` に形式番号付きのJSONを保存する。既存行はNULL。SQLite・PostgreSQLの追加migrationとTursoの起動時不足列追加に対応する。
- 保存APIは部品数・長さ・型・URLを検査し、本文はプレーンテキストとして表示する。URLはHTTP(S)のみ。外部HTMLの入力や埋め込みは受け付けない。
- PATCH時に編集開始時の本文とDBを比較し、古い画面からの上書きを409で拒否する。本文を送らない旧画面の保存では本文を保持する。
- 失敗時は入力を残す。同じタブ内の画面移動では下書きを保持し、sessionStorageが利用できる環境では再読込後も復元する。URLの入力途中も下書きとして保持するが、不正なURLは保存できない。
- 無効にした紹介本文は公開APIに出さない。公開一覧には本文を含めない。紹介画像は、そのシリーズに属する公開・非削除写真だけ。非公開／削除済み／外した写真の説明文も出さない。
- 画像は縦横比を保つ。画像の追加・公開状態は既存の写真管理を使う。

## 初期版の範囲

文章・写真や作品画像・担当／期間などの情報・記事や動画等への外部リンクを組み合わせる。新しい汎用メディア管理、動画／音声ファイルの配信、動画の直接埋め込み、自由配置、独自ページ階層、問い合わせフォームの職種別再設計は含まない。相手の実績内容を聞いてから次を決める。

## 検証

共有モデルの入力検査・非公開情報除外、React描画の文字エスケープ、体験版の保存・競合・文章のみ一覧を単体検証する。ブラウザsmokeは保存・並べ替え・公開表示、保存失敗と移動後の下書き、写真表示へ戻しても本文が残ることをPC／スマホ、Chromium／WebKitで確認する。

実APIは接続先の隔離検査が通った一時SQLiteに限定し、作成、非公開404、公開一覧、古い保存409、不正URL400、旧画面相当の更新、本文を無効にした場合の公開除外を確認する。本番へのサンプル追加や設定変更はしない。実行結果・公開状態は `task.md` と日次ログに記録する。
