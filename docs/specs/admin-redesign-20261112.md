## 2. 設計の決まり

### 2.1 並びは、実際のサイトと同じにする

- 「サイト」の中の並びは、**公開サイトのページそのもの**。今の構成（`siteDesign = develop`）では:
  **トップ／Portrait／Works／Info／展示／東京プラン（持ち主のサイトだけ）／名刺のQR** ＋ **共通（メニュー・フッター・写真を開いたとき）／見た目（書体・色・文字）／そのほか**。
  今までの構成（classic）のサイトでは、今までどおり トップ／Gallery／Series／About／Contact。
- 各ページの中は、**そのページの上から見える順**に部分を並べる。部分は3種類:
  1. 設定の節（今までどおり、押すとその設定だけ出る）
  2. 写真を選んで並べる画面（今までの「ページ」の中身。トップ＝入口の2枚、Portrait、Life、展示、東京プランの作例）
  3. ほかの編集画面（料金・分類など）
- **今の構成で効かない設定は、一覧に並べない**（値は消さない。探すと「今の構成では使いません」と付いて出る）。効く・効かないは実測の表（`effects/EFFECTS.md`）で決める。
- **同じ物は1か所**。表紙（入口）の写真は「トップ → 入口の写真」だけ。Instagram など SNS の住所は「Info → 自己紹介と SNS」だけ（フッターの画面からは、そこへの入口を置く）。
- 下の入口（スマホ）は **写真／シリーズ／サイト／言葉／メニュー** の5つ。「ページ」は「サイト」の各ページの中へ入れるので、入口からは外す。

### 2.2 スマホは、中身に画面を使う

- 上の帯（サイトの名前と「メニュー」）はスマホでは出さない。「メニュー」は下の入口の5つ目。
- 「サイト」の上の帯（横に送るページ名の列）はやめ、**1行の「いまのページ ▾」**（押すと全部のページが縦に並ぶ欄が下から出る）と、右に「見る」（プレビュー）。横に隠れる入口を無くす。
- 目標: 664px のうち、中身に 540px 以上（今 454px）。保存の帯が出ても 480px 以上。
- 「ページ」「言葉」の画面にも、同じ下の入口を出す。戻る先は、来た場所。

### 2.3 見た目の決まり（管理画面の全部の画面で同じ）

「シンプルすぎて見づらい」の原因は、段の差が無いこと。大きさ・太さ・面で段を作る。

| 物 | スマホ | PC |
| --- | --- | --- |
| 画面の題 | 22px／600（和文は明朝のまま可） | 24px |
| まとまりの題（設定の中の小見出し） | 16px／600、上に 1px の罫と 24px の間 | 同じ |
| 欄の名前 | 14px／600 | 13px／600 |
| 入力する文字・選ぶ文字 | 16px（iPhone が拡大しない） | 14px |
| 注記 | 13px／400、色は1種類（`--admin-muted`） | 12px |
| 一番小さい文字 | 12px（数・印だけ）。10〜11px は使わない | 11px |

- **入力欄は白い地＋1px の枠**（今の灰色の地は、押せない欄に見える）。高さ 48px（PC 40px）。フォーカスは濃い枠。
- **まとまりは面で分ける**: 設定の画面は、まとまりごとに白い面（角 10px、内側 16px、面の間 12px）。面の中の欄の間は 16px。地の色は今の紙の色。
- **押す物は 44px 以上**（スマホ）。隣どうしは 8px 以上あける。
- **選ぶ物（2〜4択）は同じ形**: 高さ 44px の並びのボタン、選んだ物は濃い地に白い字。
- **色**: 文字 `--admin-ink`、控えめ `--admin-muted`（1種類）、罫 `--admin-line`、差し色は今のまま。暗い表示でも同じ段の差。
- **動き**: 面や欄は動かさない。下から出る欄だけ 0.2 秒で出る（動きを減らす設定では出ない）。

### 2.4 探す

- 探す欄は、画面の名前だけでなく**欄の名前**でも当たる（「Instagram」「ロゴ」「メール」）。当たった欄のある画面を開く。

### 2.5 重なりを作らない

- 「トップの写真と順番」の「＋」「拡大」の重なりを直す。ページの中に送り枠を入れ子にしない。
- 下に固定する物は、下の入口・保存の帯・選択の帯の3つだけ。積む順は 下の入口 → その上に保存／選択の帯。中身の最後の欄は、必ずその上まで送れる。
