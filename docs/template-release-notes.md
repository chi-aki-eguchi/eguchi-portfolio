# 配布テンプレート更新履歴

セットアップ担当者は、一番上の更新だけを確認します。詳しい操作は
[template-update-guide.md](./template-update-guide.md) を使います。

## 2026-07-16 — T-5〜T-7 + 修正2件

- 10分更新: **可**
- 目標commit: `5ea948b`
- DBマイグレーション追加: なし
- settings追加: なし（既存設定はそのまま残る）

主な改善:

- SNS共有カード(`/og-default.png`)の文字化け修正（日本語含むサイト名を同梱書体で描画）
- 販売ページを「Portfolio Kit」へ再構成（旧 `/service` は自動転送。Service機能OFFの配布先には影響なし）
- Service機能をONにした配布先で、連絡先メール未設定時に制作者のメールが表示されていた問題を修正
- 配布先サイトの更新手順書を整備（この手順そのもの）

更新後の確認:

1. `/og-default.png` を開くと、配布先のサイト名が文字化けせず表示される。
2. フッターのテンプレートクレジットのリンクが `akieguchi.com/portfolio-kit` へ飛ぶ。
3. トップと `/gallery` の写真・設定が残り、`/admin/login` からログインできる。

- 10分更新: **可**

2. フッター最下部に `Site template by Aki Eguchi` が控えめに表示される。
3. `/og-default.png` を開くと、配布先のサイト名を使った画像が表示される。

Service機能は既定OFFです。必要なサイトだけ、更新確認後に管理画面からONにします。
