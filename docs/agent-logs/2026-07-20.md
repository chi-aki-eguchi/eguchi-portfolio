## タスク: Codex指摘5件の修正

1. **service-config: migration金額誤検知（P1）** — isLegacySelfPlan を「¥10,000 かつ 名称署名(自分で立てる|self)」の
   AND条件に変更。金額だけの一致で正当なカスタム2プラン（例: Basic ¥10,000 + Premium ¥30,000）を
   既定文面で上書きする事故を防ぐ。旧プラン名を独自変更していた保存データは取りこぼすが、
   その場合は「旧2プラン表示が残る」だけでデータ破壊は起きない安全側に倒した（Codexも妥当と確認）。
2. **service-config: points要素の型チェック漏れ（P1）** — isPlan に every(string) を追加。壊れたプランのみ除外し、
   同居する正常プランは残す（filter挙動）。回帰テスト2件追加。
3. **画像in-flight共有abort（P1）** — resizeInFlight を {promise, controller, waiters} に変更。
   各リクエストは joinInFlightVariant で待ち、中断は「全waiterが去った時のみ」共有側へ伝える。
   掃除は共有Promise決着時に移動（従来は最初のリクエスト完了時でエントリが早消えし二重変換の余地）。
   Codex再指摘P1対応: 決着時に必ず controller.abort() し、timeout後も待ち行列に残る処理を打ち切る。
   - 見送り(理由付き): 実行中sharpの中断（キャンセルAPIなし・従来も完走仕様）/
     timeout後の同一キー二重変換抑止（旧実装も許容。抑止すると直後の正当な再リクエストが即404になり可用性低下）
4. **admin-demoキャッシュ残留（P2）** — デモ終了時に queryClient.removeQueries() で共有キャッシュを破棄。
   fetch復元だけではstaleTime内（設定60s・一覧5分）の通常ページがデモ内容を表示し続けるため。
5. **/admin/demo のHTTP 404（P2）** — SPA_STATIC_PATHS に追加（LPから2箇所リンクされる実在ページ。
   HTML自体は表示されるがstatusが404で、監視・リンク検査が「存在しないページ」扱いしていた）。
