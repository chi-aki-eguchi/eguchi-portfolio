A SMALL TOOL FOR PHOTOGRAPHERS

写真を渡して、
選んでもらう。

写真の候補を1つの閲覧ファイルにまとめ、選ばれた写真とコメントを受け取ります。写真の処理は、このパソコンの中だけで行います。

01　候補をつくる

JPEG・PNG・WebPを追加。確認用の小さい画像に変換します。

02　ファイルを渡す

閲覧用HTMLを相手へ。PCのブラウザで写真を選べます。

03　回答を受け取る

返送された回答を開くと、選択・コメントが一覧になります。

案件の設定

0にすると枚数を制限しません。
追加する写真に焼き込みます。変更は追加後の写真には反映されません。

閲覧ファイルと案件ファイルを両方保存してください。案件ファイルは回答を照合するために使います。

続きから開く

回答者ごとに1件ずつ確認します。新しい回答を読むと表示を置き換えます。

使い方と対応範囲
  1. 写真を追加し、案件名・説明を入力します。
  2. 「案件ファイルを保存」で自分用の控えを残します。
  3. 「閲覧ファイルをつくる」でHTMLを保存します。
  4. 閲覧用HTMLだけを、合意したファイル共有先で相手に渡します。
  5. 相手はPCのブラウザで開き、写真を選び、回答JSONを保存して返送します。
  6. 自分の案件ファイルを開き、回答を読み込むと結果が出ます。

対応：PC版Chrome・Edge・Safari。スマートフォン、RAW、HEIC、動画、色管理された校正、リアルタイム共同編集は対象外です。製品版は300枚、1画像30MBまで。写真を多く扱う場合は800pxで分割してください。

HTML添付を拒否するメールサービスでは、ZIPにして合意済みのファイル共有先で渡してください。受信側はダウンロード・解凍してブラウザで開きます。

透かしはコピーを完全に防ぎません。閲覧ファイル自体に写真が入ります。閲覧権限や有効期限を強制する機能はありません。

制作元への写真送信・アクセス解析・アカウント登録はありません。原本は読み取り専用で扱い、書き換えません。
