# 企画書 #02 — 依頼導線／コンバージョン設計（仕事につなげる）

状態: **提案（実装不要・主に秋さんの設定/文章で点火）** ／ 起案 2026-06-14 ／ 区分 A 寄り

## 1. なぜこれが一番効くか
写真サイトの目的が「仕事の問い合わせ」なら、最大の伸びしろは**眠っている導線を点火すること**。
仕組みは既に全部実装済み：
- 閉じの依頼バンド `InquiryCta`（Top/Gallery/Series の足元・editorial で控えめ）
- 問い合わせフォーム（name / email / subject選択 / message・honeypot・検証・フォーカス制御）
- メール/SNSフォールバック（formspree未設定でも mailto と Instagram/X）
**だが `homeCtaEnabled=off`、CTAコピー空、料金プラン空** で、訪問者が「依頼できる」と気づけない。

## 2. 訪問者の動線（現状の摩擦）
1. トップでヒーロー → 作品が流れる（◎ 写真は強い）
2. **ここで「この人に頼める」と気づく接点がない**（CTA off）→ 離脱
3. /contact に自力で辿り着いても、**何を頼めて・いくらで・いつ返事が来るか**が分からない → 送信前に離脱

→ 写真の強さが商談に変換されていない。直すのは設定と短い文章だけ。

## 3. 提案（秋さんの設定/文章で完結。コード不要）
### 3-1. 依頼バンドを点火（最優先・5分）
- `homeCtaEnabled` → **on**
- `homeCtaTitle` 例:「撮影のご依頼」
- `homeCtaText` 例:「ポートレート・出張撮影・作品制作のご相談を承っています。まずはお気軽に。」
- `homeCtaButton` 例:「お問い合わせ」

### 3-2. /contact に「依頼の前提」を3点だけ書く（信頼の核）
`contactIntro` に簡潔に:
1. **何を撮るか** … 例「ポートレート / 家族 / 出張 / 物撮り」
2. **目安料金 or 応相談** … 数字が1つあるだけで送信率が上がる（料金プラン欄を活用）
3. **返信目安** … 例「2〜3日以内にご返信します」

### 3-3. subject 選択肢を「相談の種類」に最適化
`contactSubjectOptions`（現状の select）を依頼分類に:
例「撮影のご依頼 / 料金について / プリント購入 / その他」
→ 秋さん側で問い合わせを仕分けしやすく、訪問者も選びやすい。

### 3-4. formspree の死活確認（必須・最優先）
`formspreeUrl` が空だとフォームが出ず email/SNS フォールバックのみ。
**本番 /contact を開いて「フォームが出るか / 準備中です。になっていないか」を確認**。
formspree を使うなら URL 設定、使わないなら `contactEmail` を必ず入れる。

## 4. 効果測定（GA4 は導入済み G-NKECCDLXYD）
- 点火後、GA4 で `/contact` 到達数と離脱を見る。
- 可能なら将来 CTAクリック / フォーム送信を GA4 イベント化（別企画・小さなコード追加。今回は提案外）。

## 5. 将来のコード提案（承認後・別サイクルで企画化）
- フォーム送信成功を GA4 `generate_lead` イベントに（計測の核）。
- 作品個別ページ/ライトボックスから「この雰囲気で依頼」への動線（文脈つき問い合わせ）。
- 実績/お客様の声セクション（信頼の補強）。
→ いずれも本企画では**提案のみ**。実装は別途承認後。
