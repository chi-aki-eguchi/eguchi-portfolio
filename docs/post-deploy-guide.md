# デプロイ後ガイド（写真家本人向け）

このページは、**Railway の「Deploy」ボタンから自分のサイトを公開して、
写真を入れ始めるまで** の手順です。プログラミングの知識はいりません。
画面に出てくる英語のボタンは、押す場所をそのまま書いています。

所要時間: だいたい 10〜15 分（うち数分は組み立ての待ち時間です）。

## 先に用意するもの

1. **パソコン（推奨）** — この設定作業は、画面の広いパソコン（Mac / Windows）で
   行うのがおすすめです。スマホでもできますが、ボタンが小さく操作しづらいことが
   あります。写真のアップロード（手順⑦以降）はスマホでも大丈夫です。
2. **Railway のアカウント** — 無料で作れます。GitHub アカウントがあれば、
   それでログインできます。
3. **管理画面に使うパスワードを1つ決めておく** — あなただけが使う、写真や
   文章を編集するためのパスワードです。8文字以上で、推測されにくいものにします。
   忘れないようにメモしてください。

> **料金について:** Railway には無料の試用枠があり、写真ポートフォリオのような
> 小さなサイトなら費用は少額で、使った分だけの支払いです。デプロイの途中で
> クレジットカードの登録を求められたら、想定どおりの動きなので登録して進めて
> 大丈夫です。**金額や支払いが不安なときは、登録の前にサイトを渡してくれた人に
> 確認しても大丈夫です。**（正確な料金は時期やプランで変わるため、心配なら先に相談を。）

## 手順

### ① Deploy ボタンを押す

受け取った「Deploy on Railway」ボタン（またはリンク）を開きます。
Railway のデプロイ画面が出ます。まだログインしていなければ、ここでログインします。

### ② パスワードを入力する

デプロイ画面には、英語の項目名（例: `ADMIN_PASSWORD`, `DATABASE_URL` など）が
縦に並んだ設定の一覧が出ます。その中から **`ADMIN_PASSWORD`** という名前の行を
探します。

**ふつうは `ADMIN_PASSWORD` の欄は空です。その右の空欄に、さきほど決めた
パスワードを入力すれば完了です。**

> ※ もし `ADMIN_PASSWORD` に最初から文字が入っていたら、それを消してから、
> 自分で決めたパスワードに置きかえてください。
> ※ もし `ADMIN_PASSWORD` の欄が見当たらなくても、そのまま進めて大丈夫です。
> あとから（手順⑥でログインできないとき）設定できます。

その他の欄（データベースや写真の保存先など）は、**最初から入っているまま**
で大丈夫です。自分で書き換える必要はありません。

### ③ 「Deploy」を押して待つ

`Deploy`（または `Deploy Now`）ボタンを押します。Railway が自動でサイトを
組み立て始めます。

組み立てが始まると、画面の中央に四角いカードが何枚か並びます。
**この四角ひとつひとつを Railway では「サービス」と呼びます。** 多くの場合、

- サイト本体の **web**
- データベースの **Postgres**（または PostgreSQL）
- 写真の保存先の **Bucket / Storage**

の3枚ほどが出ます。**このうちあなたが触るのは web だけです。**
Postgres と Storage は自動で設定されるので、開いたり変更したりしないでください。
四角の左上の名前で見分けます。

- 数分かかります。**並んでいる四角の全部が緑色のチェック（または `Active`）に
  なれば組み立て完了です。** 1つでも回転マークが続いていれば、まだ待ちます。
- 赤い表示（`Failed` / `Crashed`）が出たら、このページ下の
  「うまくいかないとき」を見てください。

### ④ 公開URLを作る

組み立てが終わっても、まだサイトを開くための住所（URL）がありません。
次の手順で作ります。**ここが一番つまずきやすい所なので、ゆっくり進めてください。**

1. サイト本体の **web** という名前の四角をクリックします（Postgres や Storage では
   ありません）。
2. 上のほうにある **Settings**（設定）タブをクリックします。
3. 設定画面を**下にスクロール**して、**Networking**（ネットワーク）という見出しを
   探します。
4. その下の **Public Networking**（公開ネットワーク）という項目に、
   **「Generate Domain」** という目立つボタンがあります。これを押します。
5. `xxxx.up.railway.app` のような URL が表示されます。
   これがあなたのサイトの住所です。

> ※ ふつうは何も聞かれず自動で決まります。もし「Port（ポート）」という番号の
> 入力を求められたら、表示されている番号のまま（例: `8080`）で OK を押して
> ください。自分で番号を考える必要はありません。

### ⑤ サイトを開く

④で出た URL をクリックして開きます。写真も文章もまだ無いので、ロゴ名や空の
ページだけが表示されます。**これが正常な「公開できた」状態です。**

> **この住所をブラウザのブックマークに保存するか、メモしておいてください。**
> あとで管理画面に入るときにも使います。
>
> 自分のドメイン（例: `your-name.com`）を使いたいときは、同じ
> **Settings → Networking** の画面の「Custom Domain」から追加できますが、
> ドメインの購入や設定が必要です。急がなくて大丈夫なので、使いたくなったら
> サイトを渡してくれた人に相談するのが確実です。

### ⑥ 管理画面にログインする

パソコンの上のアドレス欄（サイトの住所が表示されている細長い欄）をクリックし、
表示されている住所の一番うしろに **`/admin/login`** と打ち足して、Enter キーを
押します。

例: `https://xxxx.up.railway.app/admin/login`

②で決めたパスワードを入れてログインします。

> ※ パスワードをあとから変えた場合は、いったん自動でログアウトされ、ログイン
> 画面に戻ります。新しいパスワードでもう一度ログインし直してください（故障では
> ありません）。

### ⑦ 写真を入れ始める

ログインすると管理画面が開きます。まず **「はじめに」** タブを開いてください。
公開までにやることが、順番に並んでいます。

おすすめの順番:

1. サイトの名前
2. プロフィール
3. 連絡先
4. 写真をアップロード
5. 公開する写真を選ぶ
6. トップに出す写真を選ぶ

くわしい使い方は [photographer-guide.md](./photographer-guide.md) を見てください。

## 知っておくと安心なこと

Railway の設定（パスワードなどの「変数」）をあとから変えると、**毎回サイトが
自動でもう一度組み立て直されます（1〜3分ほど）。** 変えた直後はまだ前の状態の
ことがあるので、組み立てが終わる（緑のチェックが出る）まで待ってから確認します。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| サイトの URL が見つからない | 手順④をやり忘れていないか。**web** の四角 → **Settings** → 下にスクロール → **Networking** → **Generate Domain** で作ります。 |
| ページが真っ白／`Application failed to respond` | 組み立て直後はまだ起動中のことがあります。1〜2分待ってから再読み込みしてください。 |
| 組み立てがいつまでも終わらない（緑にも赤にもならない） | 5〜10分待っても変わらないときは、一度ページを再読み込みします。それでも変わらなければ下の「困ったら」へ。 |
| ログインで「サーバー設定エラー (ADMIN_PASSWORD 未設定)」 | パスワードが空のままデプロイされています。**web** の四角をクリック → 上の **Variables**（変数）タブを開く → `ADMIN_PASSWORD` の欄に自分のパスワードを入れて **Save / Update** を押す。すると Railway がサイトを作り直すので、**Deployments** タブで緑のチェック（`Success` / `Active`）が出るまで（1〜3分）待ってから、もう一度ログインします。すぐ試すとまだ前の状態のことがあります。 |
| 「パスワードが違います」 | ②で入れたパスワードと違うものを入れています。大文字・小文字も区別されます。 |
| 「試行回数が多すぎます」 | 短時間に何度も間違えると、一時的にロックされます。15分ほど待ってからもう一度。 |
| 赤い `Failed` が出た | **web** の四角をクリック → **Deployments** タブ → 失敗したデプロイのログを開くと、`[migrate]` などの行に原因が出ます。 |

## 困ったら

無理に自分で直そうとしないで大丈夫です。サイトを渡してくれた人に、
**「Railway の画面でこの表示が出た」** とスクリーンショットを見せて相談してください。
たいていは、手順④（URL を作る）か、パスワードの入れ間違いのどちらかです。
