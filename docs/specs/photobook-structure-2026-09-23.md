## 何をしたか

- 設定 `siteDesign`（`classic` 既定 | `book`）。台帳 `settings-keys.ts`・API の既定値・管理画面「各ページの構成」。プレビューは全キーを query cache に写す既存の橋で届く。**既定は classic なので、配布版のサイトは変わらない。**
- 器（`Layout.tsx`）: book のときだけ左の余白（13rem）に名前・目次・About・Contact・制作サービス・明暗。Series / Work は「目次」1つにまとめる。制作サービス・管理画面（`/portfolio-kit` `/start` `/service` `/tools` `/admin`）は従来の上の帯。
- トップ（`components/book/BookHome.tsx`）: 扉（縦書きの名前・目次・1枚）→ 章ごとに扉の見開きと5枚 → 「続き」から作品ページの該当頁へ。ランダムの写真束は取りに行かない。
- 作品ページ（`BookSeries.tsx`）: 扉 → 1画面に1枚（縦は左右の頁を交互、横は見開き）→ 奥付と次の章。頁に `#p-07` の番地。写真を押すと既存のビューア。
- 目次（`BookContents.tsx`、`/series` と `/work`）: 全作品のベタ焼き。**媒体は写真1枚ずつの `filmType` どおり。**フィルムは黒い帯、デジタルは紙の上。番号は作品の中の順番で、フィルムの実際のコマ番号ではないと凡例に書く。刻印・銘柄は作らない。
- 期間はデジタルの撮影日だけから組む（フィルムの `shotAt` は複写日時。31f079c と同じ判断）。
- 並び・番号は作品ページと同じ関数（`lib/book.ts` の `orderedSeriesPhotos`）から出す。

## 2026-09-23 追加の指示「写真が小さく、余白が使われていない空間に見える」

- 文字（題・枚数・頁番号）は扉の頁だけ。写真の頁には何も置かない（頁番号は読み上げ用の名前にだけ残す）。右下・左下の「いまの頁」の札もやめた。
- 写真の頁は「画面の高さ − 縁×2」と「画面の幅 − 縁×2」の小さいほうまで大きくする。縁は PC 16〜28px、スマホ 12px で上下左右同じ。頁の高さは写真＋縁なので、横長の写真の上下に余りが出ない。実測（1440×900）: 縦4:5 は 688×860、5:4 は 1076×860、3:2 は 1291×860、16:9・2.35:1 は横 1396（左右の縁22px）。
- 5:4 のように横長でも正方形に近い写真は、画面の高さで大きさが決まり、横幅いっぱいにはならない（全体を見せるため切り抜かない）。
- 写真の頁（トップ・作品ページ）では本文を左の列の下まで広げ、写真の頁を見ている間は左の列を引っ込める。左の縁に寄せる・焦点が来る・上へ戻ると出る。スマホでは上の帯を同じ条件で引っ込める。
- 扉の見開きの写真も写真の頁と同じ縁まで大きくした。
