## 前提として守ったこと

- オーナーは「無駄な装飾はいらない」「元の静けさは良かった」（2026-09-08）、「AIっぽい」見た目を嫌う（2026-09-23）。動きを増やすのではなく、**写真を見る体験に意味のある動きだけ**にする。定番の「下からふわっと持ち上がる」は使わない。
- 写真の位置と大きさを動かさない（写真集の版がずれない）。切り抜かない。
- オーナー自身が「動きを減らす」設定を使っている（styles.css の同設定の節、2026-08-31）。**移動は消し、濃淡は残す**という既存の方針に従う。

## 手元で触って試す（本番の公開写真で）

```sh
cd <このリポジトリ>
git fetch origin
git switch claude/akieguchi-motion-design-s9odvq
bun install
bun run try
```

ブラウザで http://localhost:4400/ を開く（同じWi-FiのiPhoneからは、ターミナルに出る `Network:` のアドレス）。

- `packages/web/vite.try.config.ts`。本番（akieguchi.com）の**公開 API の GET だけ**を中継し、保存・削除・ログイン・管理画面の API は 403 で止める。`.env` は読まない。
- 設定の `siteDesign` だけを差し替えて返す（既定 book）。いつもの構成で試すなら `TRY_DESIGN=classic bun run try`。本番の設定は変わらない。
- 扉の名前の組み上がりはその訪問で1度だけ。もう一度見るには新しいタブ（またはシークレットウインドウ）で開く。
- 「動きを減らす」を試すには macOS の「アクセシビリティ → ディスプレイ → 視差効果を減らす」。

## 何をしたか

| 動き | どこで | 中身 | 動きを減らす設定 |
|---|---|---|---|
| 現像 | 写真集（book）の全ての写真 | 頁が画面に入ると、明るく眠い調子（紙の白）から本来の濃さへ落ち着く。1枚につき1度。画像が読み込み終わってから始める | 残す（濃淡と調子だけ） |
| 組版 | 写真集のトップの扉 | 縦書きの名前が一字ずつ、ぼけから締まる。続いて目次の行が上から順に。**その回の訪問で最初の1度だけ**（sessionStorage） | 残す（ぼけと濃淡だけ） |
| 頁の写真から開く／戻る | ビューア（全デザイン共通） | 押した写真そのものが大きくなってビューアになり、閉じると元の場所へ戻る。一覧で切り抜いていた写真は、運ぶ間に切り抜きがほどける。ビューアの中で先へ送ってから閉じると、その写真の頁へ戻る | 使わない（移動なので従来の現れ方）。頁の位置合わせは同じ |
| 頁の移り変わり | 写真集 | 次の頁が下から持ち上がらず、その場で濃くなる | 変わらず |

- 実装: `components/book/BookParts.tsx` の `useBookDevelop`、`BookHome.tsx` の `useTitleEntrance`、`lib/viewer-morph.ts`（影を運ぶ部品）、`Lightbox.tsx`、`PageTransition.tsx`、`book.css` 末尾、`styles.css` の `lightbox-morph`。
- 隠れたまま残らない仕組み: 待たせる印 `data-develop="wait"` は、見張ると決めた写真にだけ付け、見張りをやめるときは外す。見張っていない写真はいつもどおり見える。

## ついでに直した既存の不具合

- 写真集でビューアを開き、前後へ送ってから閉じると、送った先の頁へ移ったあとに**開いたときの位置へ戻されていた**（ビューアの後片付けが、開いたときのスクロール位置を最後に書き戻していた）。閉じるときにいま見ている写真の頁へ合わせ、後片付けもその位置を使う。
- 同じ写真が扉と頁の2か所に出る作品（表紙を選んだ作品）で、画面外のほうを拾わないよう、いちばんよく見えているほうを選ぶ。

- 写真のビューアを閉じると、1フレームだけ開いたときの位置へ跳ね戻っていた（ブラウザが履歴を戻すときのスクロール復元）。ビューアの履歴を積む前の項目だけ復元を manual にした。
- 扉の名前の組み上がりは、長い名前でも約1.4秒で終わるようにした（配布版の英字の既定名で3秒を超えていた）。
