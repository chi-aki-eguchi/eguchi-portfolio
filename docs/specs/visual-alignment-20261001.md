# 公開サイトの「ちょっとしたズレ」の総点検（2026-10-01）

オーナー「（トップの名前の白いもやを見て）これダサくない？」→（左メニューの
スクショで）「このちょっとのズレとかも。元々あるけどうーんってなるものも
色々見直してほしい」。

## 測り方

本番（`https://akieguchi.com`、build 60ea2298）を読み取りだけで巡回し、
WebKit（オーナーは Safari 系）で PC 1440×900・スマホ 390×844 を撮った。
スクリプトは手元の `scratch/look-review-20261001/`（git には入れない。
`capture.mjs` が全ページ、`shot.mjs` が1枚、`probe-el.mjs` が要素の幅と余白、
`edges.mjs` が名前・本文・ハンバーガーの縁）。直した後は
`bun run try`（本番の公開 GET だけを中継する手元のサーバー、:4400）で同じ
画面を撮り直した。本番の設定は変えていない。

本番の設定で効いている前提: メニューは左（`navPosition: left`）、
ページ上端の余白 0.2（`spacingPageTop`）、名前の色 `#404040`、全画面の1枚写真。

## 見つけて直したもの

| どこ | 何がずれていたか | 原因 | 直し |
|---|---|---|---|
| PC 左のメニュー | 名前だけ左、項目は中央、触れた下線は文字より 18px 左から、明暗の印は中央 | 縦並びに Tailwind の `items-center` が残っていた。今いない項目を 18px 字下げしていて、その余白まで下線が伸びた | 項目・印・JP｜EN を名前と同じ左端へ。今いるページは左の余白に下げた短い線だけ（線と下線の二重をやめた） |
| PC 左のメニュー（About・Contact） | ページを移ると項目が左右に 2px 動く | 中央寄せの基準が一番幅のある項目（JP｜EN）で変わった | 左揃えで解消 |
| JP｜EN | 選んでいない EN のほうが濃い。区切りの後ろだけ大きく空く | 今の言語を 0.76 に固定、ナビの濃さ 1 の本番では逆転。EN に上の 18px 字下げが当たっていた | 今の言語は「濃く＋下線」（メニューの今いるページと同じ印）。字下げをやめて間隔も均等 |
| PC 左メニューの全ページ | 見出しや写真が画面の上端から 10px で始まる（プライバシーの見出しは上端に接する） | 左メニューでは本文の上余白を 0 にしていた。上端の余白 0.2 と重なった。管理画面のプレビュー（狭い幅は上のメニュー）とも食い違い | 上のメニューの時と同じ 56px を空ける。トップの写真は今までどおり上端から |
| PC 左メニューのトップ | 全画面の写真が画面より 56px 短く、下に WORKS の帯がのぞく | 全画面の高さが「画面 − 上の帯」の式のまま | 左メニューでは帯のぶんを引かない（`--header-h: 0`） |
| PC 全ページのフッター | 「このサイトと同じ仕組みで…」の行と区切り線だけ 88px 左へずれる | この行だけ左メニューの幅を空けていなかった | 外側に行を作り、main・footer と同じだけ空ける |
| スマホのトップ | 「撮影のご依頼」が画面の左端に接する（余白 0） | トップでは余白の無い器に直接置いていた | 本文と同じ器（左右 16px）に入れる |
| スマホ全ページ | 名前・メニュー・フッターの縁が 24px、本文と写真の縁が 16px | ヘッダーとフッターだけ古い 24px のまま | すべて本文の縁（`--page-inset`、スマホ 16px・PC 24px）へ。ハンバーガーの線の右端も本文の右端へ |
| スマホのメニュー | 今いるページだけ文字が 21px 右へずれる | 前に点を置いていた | 点をやめて「濃く＋下線」 |
| スマホの短い文 | 「…ご相談くださ／い。」と最後の1文字だけが次の行 | 折り返しの調整なし | `text-wrap: pretty`（依頼の文）、`balance`（制作の案内の1行） |
| PC 上のメニュー（他の設定で使う形） | 名前が本文より 24px 内側 | ヘッダーだけ 48px | 本文と同じ 24px |

縁をそろえる規則は公開サイトのヘッダー（`.site-header > nav`）だけに付けた。
もとの `header > nav` は管理画面の上の帯（`.admin-book__bar > nav`）にも
当たっているので、そちらの余白は変えていない。

## オーナーの判断を待つもの

- **トップの名前**: 白いもやは、名前の色が濃いグレー（`#404040`）のとき
  読めるように自動で敷くもの（9/30 の修正）。写真を曇らせるので、色を
  白に戻す（設定の「名前の色」を空にする）のが一番きれい。4段
  （江口秋／エグチアキ／Aki Eguchi／Photography）を2段にするなら、
  読みがなと肩書きを空にする。どちらも設定の値なので、オーナーの了解を
  得てから変える。比較画像は手元で撮った（PC・スマホ）。
- **Series 一覧（PC）**: 列数が 3 で4組あるので、4組目だけが2段目に1枚。
  管理画面の列数を 2（2×2）か 4（1段）にすれば揃う。設定で選べるので
  コードは変えていない。
