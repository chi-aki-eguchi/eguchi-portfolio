# 展示の欄と、依頼向けに戻したトップ（2026-11-10）

2026-11-10 オーナー依頼。サイト全体の点検（同日。本番を14ページ、スマホ幅とPC幅で撮って数えた）のあと、「改善して欲しい。展示は新しく展示の欄を作る？作れる？今までの展示もこの形式で残せるかな？写真があれば」。

点検で数えたこと（本番 build `16e9bd7e`、解析の通信は遮断）：

- トップは会期（11/1〜3）の終わった展示のままで、料金も依頼の入口も0件。開いてから写真が見えるまで約4秒（名刺の見せ場）。
- Portrait の「撮影のご依頼」はスマホで 7.4 画面ぶん下。Portrait・Life の検索向けの説明は「江口秋の写真ポートフォリオ。」だけ。
- Info は遅い回線で読み込み中に大きくずれる（スマホ・4G 相当で、ずれの指標 0.805。`/info#request` は 1.458。良好の目安は 0.1 以下）。

## 展示の欄

正本は `packages/web/src/shared/exhibitions.ts`。

- 住所は一覧 `/exhibition` と、1件ずつの `/exhibition/:slug`。新しい構成（siteDesign = "develop"）のサイトで、公開できる展示が1件でもあるときだけ在る（無ければサーバーも 404）。メニューに「Exhibition」（Series と Info の間）。
- **日藝祭 2026 は `/exhibition/2026-nichigei`。**今までのトップと同じ組み立て（会場の壁・同じ順の5枚・詩・名刺・QR の人への部分・名刺で始まる見せ場）を、そのまま1件のページにした。設定（exhibitionTitle など）・同梱の写真・管理画面の欄は変えていない。仕様は [exhibition-top-20261031.md](exhibition-top-20261031.md) のまま。
- **足した展示**（前の展示・次の展示）は、設定 `exhibitionArchive`（JSON の並び。1件は slug・題・会期・添える文・写真の ID・写真ごとの題）。写真はライブラリの写真を選ぶ。先頭の写真が切り抜かない表紙、選んだ順に続き、最後に添える文（短い詩は紙に縦書き、長い文は横書き）。題がページの見出し。壁の配置・名刺・QR の人への部分・開いた瞬間の見せ場は付かない。
- 写真を1枚も選んでいない展示は公開に出ない（管理画面にだけ在る）。
- 並びは新しい順。会期の文から年と月を読む（「2025年10月」「2025.10」「2025」。全角の数字も）。読めない物は後ろ。
- 足した展示の住所は、公開する前（写真なし）に会期を書くと年が頭に付く（`2025-…`）。公開したあとは、共有された住所が切れないように変えない。

## トップ

- **保存値が無いときは、いつものトップ**（表紙＋扉の目次）。それまでは持ち主のサイトだけ展示がトップだった（`exhibitionStatus`）。本番は `homeExhibition` を保存していなかったので、この版の公開でトップが表紙に戻る。
- 設定の名前は `exhibitionOnTop`。初めは `homeExhibition` のままにしたが、本番にはその名前で「on」が保存されていて、公開してもトップが展示のままだった。同日、名前を付け替えて古い保存値を読まないようにした（本番の設定は書き換えていない）。
- 会期中だけトップにも出したいときは、管理画面「ページの写真」→「展示」→ 日藝祭の展示 →「トップ：展示」。今までどおり。
- **名刺の QR（`/card.html`、印刷済み）**は、トップが展示の間は `/` へ、そうでなければ `/exhibition/2026-nichigei` へ通す。QR の数え方・印（Cookie）は今までどおり。展示の無いサイトでは今までのリンク集。

## 依頼の入口の1行（InquiryLine）

`components/InquiryCta.tsx`。料金の文（設定 `homeCtaText`）と、Info の料金と依頼の位置（`/info#request`）への入口（見出しの言葉 `homeCtaTitle`）。依頼の帯を出す設定（`homeCtaEnabled`）のサイトの、新しい構成でだけ出る。

- **トップ**：表紙のすぐ下。表紙をこの1行ぶん短くして（`--hero-reserve`。スマホ 72px、広い画面 56px）、開いた最初の画面の下端に料金と入口が入る。扉の目次の後ろにあった帯は外した（すぐ上が Info の扉）。最初の画面に入るのは、表紙が画面いっぱいの出し方（`heroDisplayMode` = fullscreen。本番の設定）のとき。ほかの出し方では、表紙の続きに出る。
- **Portrait には置いていない。**写真の上に置く版を作ったが、見出しを出さない設定では写真を上の帯のすぐ下から始める決まり（2026-10-12 の余白の指摘から。smoke「写真は幅を使い切り、余白は区切りにだけ使う」）とぶつかるので外した。Portrait の依頼の入口は、今までどおりページの終わりの帯（スマホで約7画面ぶん下）。近づけるなら、スマホの上の帯に小さな入口を置く案がある（オーナーの判断）。
- 展示の画面には出さない（詩の余韻のあとに料金を置かない、は今までどおり）。

## 検索・共有

- `/exhibition` の題名は「Exhibition」、1件のページはその展示の題。説明は「（名前）の写真。（題）、（会期）。」、共有の写真は先頭の写真。添える文は、JavaScript を動かさない読み手への本文にもなる。サイトマップと、検索ロボット向けのリンクに載る。
- Portrait の説明は「（名前）が撮ったポートレート。＋料金の文」、Life は「（名前）が撮った日常の写真。」（それまでは、どちらもサイト全体の一文）。

## Info のずれ

- 自己紹介は写真が届くまで1画面ぶんの場所を取って待つ作り（`.site-page-hold`）だが、Info の中ではこの場所取りまで外す指定が当たっていて、依頼の欄が先に画面の上へ出てから押し下げられていた。場所取りを戻した（`develop.css`）。
- `/info#request` の、印へ合わせ直す時間を 1.5 秒 → 6 秒（自己紹介は写真を最大 2.5 秒待つ）。読む人が触ったらやめるのは今までどおり。

## 管理画面

`/admin/pages` の「展示」タブ。上に、編集する展示を選ぶ並びと「＋ 展示を足す」。

- 日藝祭の展示を選ぶと、今までの欄（トップの出し方・QR の数とひとこと・写真・題・会期・詩・QR の人へのひとこと・写真ごとの題）。
- 足した展示を選ぶと、写真（ライブラリから。足す・外す・並べ替え）・題・会場と会期・添える文・写真ごとの題・「この展示を消す」（消した直後は「元に戻す」が出る）。
- タブの数字は、選んでいる展示の写真の枚数。「サイトで見る」は、その展示のページを開く。
- 配布版の管理画面に展示のタブを出さないのは今までどおり。
