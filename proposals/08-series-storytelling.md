# 企画書 #08 — シリーズ「物語化」編集設計（小さな写真集をつくる）

状態: **提案（編集・キュレーション中心 / コード不要）** ／ 起案 2026-06-14

## 1. 狙い
単発写真の集合から、**テーマごとの“小さな写真集”**へ。シリーズが立ち上がると、
- 共有したくなる単位になり（#03 SNS）、
- statement が信頼と依頼につながり（#02）、
- title が画像検索に効く（#05）。
一粒で三度おいしい、サイトの核となる編集作業。

## 2. 器はもう全部ある（コードで確認）
`series` テーブルに **title / subtitle / statement(コンセプト文) / coverPhotoId / sortOrder / isPublished**。
series-detail は title・subtitle・statement・表紙・写真一覧を**すべて表示済み**。
写真側は **displaySize(S/M/L)** と **sortOrder** で誌面の強弱と並びを演出できる（design-spec 2章）。
→ **足りないのはコードでなく「編集の判断」と statement の文章だけ。**

## 3. 写真集として組む（編集の原則）
- **タイトル & サブタイトル**：作品名＋短い副題。例「潮汐 — 逗子の海と少女」。検索にも共有にも効く。
- **statement（序文・2〜4文）**：何を/なぜ撮ったか、見る人への入口。長文不要。**写真集の最初のページ**の役割。
- **表紙(coverPhotoel)**：一番“上手い”写真より、**世界に招き入れる1枚**を選ぶ。シリーズの空気を代表する顔。
- **シークエンス(sortOrder)**：写真集は順番が命。
  - 強い「掴み」で始め、
  - 中盤に緩急（寄り/引き、明/暗、静/動）をつけ、
  - 最後は余韻の残る1枚で閉じる（起承転結）。
- **S/M/L で誌面の呼吸**：全部同じ大きさにしない。**ここぞの1枚を L**、つなぎを S/M。
  見開きの「間」を作ると写真集感が出る（完全自由配置はしない＝design-spec の方針）。
- **枚数**：詰め込みすぎない。**選び切る**ことが質。15〜30枚程度を目安に“捨てる勇気”。

## 4. statement の作り方（テンプレだけ。文章は秋さんの言葉で）
書きやすい型（穴埋め）：
1. **どこで・何を** … 「逗子の海辺で、夏の終わりの光を」
2. **なぜ惹かれたか** … 「移り変わる潮と、子どもの一瞬の表情に」
3. **見る人へ** … 「静かな時間を、写真の中で過ごしてもらえたら」
→ AIに丸投げせず、**秋さんの実感の言葉**が一番強い。型は出すが、声は本人のもの。

## 5. シリーズの育て方（運用）
- まず **1シリーズを“完成形”に**して見本を作る（タイトル/序文/表紙/並び/S・M・L 全部整える）。
- それを基準に他シリーズへ展開。
- 公開したら #03 の通り SNS で「新シリーズ公開」を告知 → /series/該当 へ誘導。
- GA4 で見られているシリーズを把握 → トップの並び(`topWorksIds`/`seriesLayout`)に反映。

## 6. 連携（他企画との接続）
- statement を埋める → **#02 依頼導線**の信頼材料に。
- 各写真に title → **#05 画像SEO**。
- シリーズ単位の OGP は実装済 → **#03 で共有映え**。
- 制作記を **note**（#03/#04）に書き、サイトの該当シリーズへ相互リンク。

## 7. 秋さんへの確認
1. **最初に“完成形”にするシリーズ**はどれにするか（代表作1つ）。
2. statement の型（§4）で書き進められそうか、別の切り口が欲しいか。
3. シリーズあたりの枚数の方針（絞る/たくさん見せる）。

→ コード変更なし。サイトの最も写真集的な機能を、編集の力で主役にする企画。
