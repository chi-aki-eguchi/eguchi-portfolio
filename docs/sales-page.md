# Aki Eguchi Portfolio Kit

写真が主役の、あなただけのポートフォリオサイト

テンプレートと格闘せずに持てる、静かで完成されたポートフォリオ。
管理画面から写真、プロフィール、連絡先を入れて、自分の作品を見せる場所として運用できます。

> 実際にこの仕組みで動いているサイト: **akieguchi.com**
> 作品一覧 / プロフィール / 問い合わせ導線は、このサイト内でそのまま確認できます。

---

## これは何

- **あなた専用のポートフォリオサイト**です。共有のサービスに間借りするのではなく、
  あなたの名前・あなたのドメインで持てます。
- **写真が主役**の、編集された静けさのあるデザイン。最初から整っているので、
  デザインを一から考える必要はありません。
- **コードは不要**。写真と文章は、ブラウザの管理画面から入れます。
- 中身は実際に使われている本物のサイト（akieguchi.com）と同じ仕組みです。
  「作りかけの何か」ではありません。

## できること

- **写真のアップロード** — 上げるだけで自動で軽く最適化。スマホでもサクサク表示。
- **編集された見え方** — 見せたい写真を大きく、流れで見せたい写真を控えめに。
  自由配置で崩す心配なく、作品の強弱を整えられます。
- **プロフィール・連絡先・撮影依頼フォーム** — 仕事につながる導線が最初から。
- **SNS・検索に強い** — URLをSNSに貼ったときの見え方（タイトル・画像）や、
  検索エンジン向けの情報が最初から正しく出ます。
- **スマホ対応** — 見る人の多くはスマホ。最初からきれいに収まります。
- **独自ドメイン対応** — `your-name.com` のような自分の住所で公開できます。
- **ギャラリー / シリーズ / カテゴリ / 料金ページ** など、写真家に必要な構成を一通り。

## いくら

始め方が2つあり、それぞれに合わせた料金です。

### A. 自分で立てる — ¥10,000

手順書を見ながら、自分でサイトを立ち上げるコースです。

- テンプレート利用料: **¥10,000（一回）**
- 公開の場所（Railway）: **使った分の実費**（月500〜1,000円程度）
- 設定は、ボタンを押して進めるガイド付き
- 操作方法の初回相談つき

### B. おまかせ設定 — ¥30,000

設定はこちらで全部済ませて、あなたは管理画面だけ受け取ります。

- 初期設定の代行: **¥30,000（一回）**
- 月額: **なし**（公開の場所の実費のみ。月500〜1,000円程度）
- 公開後7日間の操作相談つき

> どちらの場合も、**あなたが載せた写真・文章・データは、あなたのもの**です。
> （サイトの仕組み＝テンプレートのコード自体は、お渡しする利用の範囲でお使いいただく
> 形になります。）あとからドメインを変えたり、やめたりも自由です。

### ご購入の範囲

- 1回の購入につき1サイトで利用できます。2サイト目以降は追加購入が必要です。
- テンプレートとしての再販売・再配布はできません。
- テンプレート本体の更新は現時点では無償で提供しますが、今後変更する場合があります。
- デザイン変更、個別カスタム、プランに含まれる期間・回数を超える相談や作業は、内容に応じて別途お見積もりします。

## どう始める

Stripe で決済したあと、すぐに自動でサイトが完成するわけではありません。
こちらで決済を確認し、選んだコースに合わせて次の案内を送ります。

### すぐ自分で

1. 決済後24時間以内に、購入後スタートページと立ち上げ用リンクを受け取ります。
2. 購入後に届く setup link から公開します。
3. スタートページの順番どおりに、公開URLと管理画面を作ります。
4. 管理画面の「はじめに」が、公開までの5ステップを案内します。

### おまかせにしたい

1. 決済後24時間以内に、お名前・載せたい写真・プロフィール文・連絡先など、必要な素材をご案内します。
2. 素材が揃ってから3日以内に、こちらで初期設定します。
3. 設定が終わったら、**サイトURL** と **管理画面URL・パスワード** をお渡しします。
   あとは写真を入れるだけです。

## よくある質問

- **専門知識は必要ですか？** — いりません。写真を上げて、文章を書くだけです。
- **写真やデータは自分のものになりますか？** — あなたが載せた写真・文章・データは、すべてあなたのものです。（サイトの仕組み＝テンプレートのコードは、お渡しする利用の範囲でのご利用になります。）
- **あとからデザインや文章を変えられますか？** — はい。管理画面からいつでも。
- **独自ドメインは使えますか？** — はい。お持ちのドメインを設定できます。
- **スマホだけでも運用できますか？** — スマホからも管理できます（写真の追加・更新など）。
  ただし、たくさんの写真をまとめて上げたり、最初の整理をするときはパソコンが楽です。
  最初の公開設定もパソコンをおすすめします。
