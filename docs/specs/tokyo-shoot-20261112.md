# 東京の旅行者向け撮影プラン `/tokyo`（2026-11-12）

オーナーの依頼：東京旅行中の人（主に台湾・香港の繁體字圏、次に英語圏）が撮影を申し込める1枚。この1ヶ月で予約を取ることが目的。

## 何があるか

- 住所は3つ：`/tokyo`（繁體中文）、`/tokyo/en`、`/tokyo/ja`。上の帯で切り替える。akieguchi.com にだけ在る（Portfolio Kit を買った人のサイトでは 404）。
- サイトのメニュー・帯・フッターは出さない。上は名前と言語の切り替えだけ、下に Portrait への出口1本と Instagram（オーナー「ある程度独立させた方が良くない？」）。
- 入口：Info／Contact の「English inquiries welcome.」の下に1行。JavaScript なしの読み手向けリンクにも入れてある。
- 申し込みは Contact と同じ送信先（設定 `formspreeUrl`）。件名は「東京撮影プランの申し込み」。項目名と選択肢は、どの言語のページから送っても日本語で届き、「料金の目安」が付く。決済は扱わない（日程が決まってからオーナーが個別に案内）。

## 決まっていること（2026-11-12、オーナー）

- プラン：デジタル 1時間 ¥15,000（約30枚、3日以内）／フィルム＋デジタル 1.5時間 ¥25,000（35mm 1本）／中判フィルム 1.5時間 ¥35,000（67 またはハッセル 1本）。
- 人数：2人まで同額、3人目から1人 +¥3,000。
- 受けられる日：2026年12月の日曜と火曜。過ぎた日は自動で消え、全部過ぎると日付を自由に選ぶ欄に戻る。
- 既存の「ポートレート 60分 ¥10,000」（20枚・1週間）とは別のプランとして、名前で分けて見せる。設定は変えていない。
- 写真はAIで加工・生成しない。実績数・お客さんの声など事実でないものを書かない。
