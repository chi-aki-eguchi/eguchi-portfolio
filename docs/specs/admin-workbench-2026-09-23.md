# 写真集の管理画面「作品ごとの作業台」— 2026-09-23 試作

状態: ブランチ `design/admin-workbench` の試作。**オーナーの目視確認前・未push。**

## 依頼と前提

- 管理画面の3案（A 作品ごとの作業台／B 3つの仕事に分ける／C 公開サイトの上で直す）から A。見た目（UI）と使い心地（UX）も同時に作り直す。
- 優先: 写真の取り込み・並べ替え・シリーズの編集が迷わずできること。既存機能（EXIF 取り込み、⌘K、日付の一括入力、ゴミ箱、表形式の一括編集）は減らさない。
- **管理画面はポートフォリオ制作のお客さまと同じコード**（`pages/admin.tsx` の `AdminPageContent`、見本 `/admin/demo` も同じ）。作業台は `siteDesign = "book"` のときだけ使い、いつもの構成（配布版の既定）は今までの画面のまま。

## 変える前に見つけたこと（/admin/demo・本番の公開データ、2026-09-23）

- 黒い地・小さく薄い文字・角丸の枠ボタン・細い区切り線。写真一覧の上に操作が十数個。
- 左のメニューが「写真」「サイト編集」で丸ごと入れ替わる。シリーズは写真側、トップの写真はサイト編集側。
- 「並べ替え」（手で動かす）・「並び替え」（14種の表示順）・「一覧での並び順」が似た名前。
- シリーズの画面から写真を入れられない（「割り当ては Library で」）。
- サイト編集は21節。写真集では効かない節も並ぶ。スマホは明暗の切り替えが2つ。
- HERO の写真の読み上げ名が、選ぶ前から「N番の写真を動かしています」。

## 何をしたか

- 器（`components/admin-book/BookAdminShell.tsx`）: 上に「作品／写真の一覧／サイト」の3つだけ。探す（⌘K）・サイトを見る・ログアウト。紙の地は公開サイトの明るい配色から作る（`adminThemeFromSettings(…, "light")`）。見出し・作品名は公開サイトの和文書体。
- 作品（`Workbench.tsx`）: 左に Series／Work／未整理と「＋ 新しい作品」、中央にその作品のベタ焼き（フィルムは黒い帯・デジタルは紙の上、写真ごとの記録どおり）、右に選んでいるものの欄。
  - いつも見えている操作は「写真を加える」と、コマのドラッグ（サイトの順番）だけ。
  - 写真を選ぶと: 公開／非公開・前へ／後ろへ・表紙にする・題・別の作品へ移す・ゴミ箱・「撮影情報・日付を詳しく直す（写真の一覧）」。
  - 何も選んでいないと: 作品の題・副題・作家の言葉・公開・棚（Series／Work）。変えたときだけ「変更を保存」。
  - どの操作も直後に「元に戻す」、⌘Z でも戻る。ファイルを落とす／選ぶとフィルムかデジタルかを聞いて、その作品に加える。コマを左の作品へ落とすと移る。
  - 順番の保存は全体の並びのうち、その作品の写真が占める位置だけを入れ替える（`lib/work-order.ts`）。ほかの作品の位置は動かない。
- 写真の一覧: 今までの Library をそのまま使う（EXIF・日付の一括入力・表形式の一括編集・ゴミ箱）。写真集のときだけ名前を言い分ける — 「サイトの順番を変える」「一覧の表示順（サイトは変わりません）」。
- サイト: 自前の目次（写真集／作品以外のページ〔About・Contact・名前と連絡先・料金・ポートフォリオ制作〕／見た目／そのほか）。写真集では効かない節（トップの見せ方・写真一覧のレイアウト・メニューとヘッダー・デザインの出発点・写真の表示アニメーション・ページの余白）は値を残して隠す（`SettingsTab` の `hiddenSectionIds`）。
- 取り込みの手順を `lib/admin-upload.ts` に切り出し、写真一覧と作業台が同じ手順を使う。
- HERO の読み上げ名: 選ぶ前は「N番の写真を、動かす写真に選ぶ」。
- スマホ: 作品は横に並ぶ札、写真を選ぶと下から欄が出る（公開・前へ／後ろへ・表紙）。

## 確かめ方

- 手元の確認用サーバー（未追跡の `packages/web/vite.book-preview.config.ts`）は、本番の公開 API を GET だけで読み、管理 API は手元のメモリで答える。書き込み・取り込みは本番へ送らない。
- 実ブラウザで: ドラッグで順番 → ⌘Z で戻る、非公開 → 元に戻す、1枚の取り込み。いつもの構成の管理画面は変更前と同じ。

## 2026-09-23 追加（オーナーの6点）

- 何番目へ: 写真を選ぶと「何番目へ移すか（1〜N）」「先頭へ」「最後へ」。複数を選んだときは「選んだN枚を、何番目から並べるか」。
- 作品どうしの順番: 左の一覧の作品をドラッグ（/admin/series/reorder）。元に戻せる。
- 取り込みの媒体: カメラの記録（EXIF の Make・Model）があればデジタル、無ければフィルムで自動登録し、取り込み後の一覧で1枚ずつ／まとめて直せる。**フィルムをデジタルカメラで複写した画像はデジタルと判定される**ので、その場合はそこで直す。
- 暗い表示: 写真集の管理画面だけの「暗い表示／明るい表示」（既定は明るい紙）。フィルムの黒い帯に縁。
- 右の欄の文字: 見出し・説明 14.5〜15px、入力 16px、濃さを上げた。
- まとめて選ぶ: クリック＝1枚、⌘クリック＝足す・外す、Shift クリック＝範囲、「まとめて選ぶ」＝指で足す・外す、「すべて選ぶ／見えているN枚を選ぶ」。選んだ写真をまとめて公開・非公開・何番目へ・別の作品へ・ゴミ箱。検索（ファイル名・題・カメラ・日付）と媒体・公開の絞り込み。
- 2000枚の確認（手元の見本のみ。1作品500枚＋6作品×150枚＋未整理600枚＋本物133枚＝2133枚）: 数字は `task.md` と開発ログ。スマホの公開目次が重かった（開くまで2.4秒・固まる1.5秒、CPU 1/4）ので、作品ごとに40コマずつ描いて下の端で残りを描くようにし、1.2秒・0.4秒になった。作業台と目次のコマは画面の外を描かない（content-visibility）。

## 残り

- 並べ替え中に別の画面で順番が変わった場合（409）は読み直して知らせるだけ。複数枚を選んでまとめて動かす操作は写真の一覧の「サイトの順番を変える」に任せている。
- 作品の並び（SICF と Rintaro のどちらが先か）の入れ替えは、まだ作業台に無い（既存のシリーズ画面の ↑↓）。
