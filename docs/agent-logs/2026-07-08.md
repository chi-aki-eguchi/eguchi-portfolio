## Part 0: ギャラリーホバー演出の確定(保留項目1の決着)

- **タスク名**: ギャラリーホバー A/B/C の確定
- **選んだ方針**: 案C(動きなし・影だけ深くなる)を採用。
  `.photo-card:hover` の浮き(-4px)と、写真の拡大(1.03倍)+明度補正(+4%)を削除。
  影の深化(`--shadow-photo-hover`)のみ残した。
- **迷った点と理由**: オーナーは3案の差を体感できなかったため、指示どおり
  「最も実装が単純で保守しやすい案」で判断した。
  - 案A(現状維持)は編集作業ゼロだが、ルールが2箇所(カードのtransform+imgのscale/filter)に
    分かれ、LQIPのブラー解除フィルタと transition-duration を共有する繊細な作りで保守コストが高い。
  - 案Bも img 側の scale ルールが残るため構造は案Aと同じ。
  - 案Cは transform・filter への関与が完全に消え、hover は box-shadow 1プロパティだけになる。
    写真の色・大きさを一切変えないため写真家的な懸念(明度が変わる)も同時に解消。
  - 付随して不要になった打ち消しルール(`.photo-card-quiet:hover` と
    `.collage-card .photo-card:hover` の `transform: none`)も削除し、コメントの古い記述を更新。
- **触らなかったもの**: collage レイアウトの額縁ごと動く hover(-3px + 1.015倍)は
  別の意図的デザイン(額と写真が一体で動く)なので維持。tile-caption のフェードも
  「演出A/B/C」の対象外(タイトル表示の機能)なので維持。
- **要相談**: なし
