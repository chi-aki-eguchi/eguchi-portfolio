## 公開・立ち上げ

**Q. どうやってサイトを公開するの？**
自分で立てるなら [post-deploy-guide.md](./post-deploy-guide.md) の手順どおりに。
おまかせ（コンシェルジュ）なら、設定担当者に頼めば URL とパスワードを受け取るだけです。

**Q. 公開したのに URL が見つからない／ページが真っ白。**
[post-deploy-guide.md の「うまくいかないとき」](./post-deploy-guide.md#うまくいかないとき)を見てください。
多くは「公開URLを作る（Generate Domain）」のやり忘れか、起動直後の数分待ちです。

**Q. 公開までどれくらいかかる？**
自分で立てて、だいたい 10〜15 分です（うち数分は組み立ての待ち時間）。

## ログイン・パスワード

**Q. 管理画面はどこ？**
サイトの URL のうしろに `/admin/login` を付けて開きます。

**Q. パスワードを忘れた／変えたい。**
Railway の **web** サービス → **Variables** → `ADMIN_PASSWORD` を新しい値にして保存すると、
サイトが作り直され、数分後に新しいパスワードで入れます。おまかせで作ってもらった場合は、
設定担当者に連絡してください。

**Q. パスワードを変えたらログアウトされた。**
仕様です（故障ではありません）。新しいパスワードで入り直してください。

**Q. 「サーバー設定エラー (ADMIN_PASSWORD 未設定)」と出る。**
パスワードが空のままです。[post-deploy-guide.md の「うまくいかないとき」](./post-deploy-guide.md#うまくいかないとき)に直し方があります。

## 写真・アップロード

**Q. どんな写真が使える？ 何枚まで？**
一般的な写真（JPEG など）が使えます。枚数の固定上限はありませんが、たくさん上げるときは
少しずつ、最初の整理はパソコンが楽です。

**Q. アップロードした写真がサイトに出ない。**
管理画面の「はじめに」で、(1) 写真が公開状態か、(2) トップ写真に選んでいるか を確認します。

**Q. アップロードで画質は落ちる？**
表示を軽くするために自動で最適化しますが（長辺 3200px・高品質）、見栄えは保つ設定です。
大切な写真は、手元にも原本を残しておいてください。

**Q. スマホだけで運用できる？**
写真の追加・更新はスマホでできます。ただし大量アップロードや最初の整理、最初の公開設定は
パソコンが楽です。

## ドメイン・URL

**Q. 自分のドメイン（◯◯◯.com）を使いたい。**
Railway の **web** サービス → **Settings → Networking → Custom Domain** から追加できます。
ドメインの購入や設定が必要なので、設定担当者に相談すると確実です。`xxxx.up.railway.app`
のままでも問題なく使えます。

**Q. URL を変えたら、SNS 共有の表示も変わる？**
管理画面の公開URL（または `SITE_URL`）を新しいドメインにそろえると、SNS 共有・検索向けの
表示も新しい住所になります。

## 料金

**Q. いくらかかる？**
始め方によって変わります。詳しくは [sales-page.md](./sales-page.md)。Railway の実費は、
Railway 側の料金改定や使用量によって変わります。

**Q. 支払い方法を登録したくない。**
公開には基本的に必要です。金額や支払いが不安なときは、登録の前に設定担当者に相談して
大丈夫です。

## データ・所有権・終了

**Q. 写真やデータは自分のもの？**
あなたが載せた写真・文章・データは、あなたのものです（サイトの仕組み＝テンプレートの
コード自体は、お渡しする利用の範囲でのご利用になります）。

**Q. バックアップはある？**
自動バックアップの整備は今後の予定です。今のところ、**大切な写真は手元にも原本を
残しておく**のが安心です。設定の控えが必要なときは設定担当者に相談してください。

**Q. やめたいときは？**
Railway のプロジェクトを止める／削除すると公開が終わります。消すとデータも無くなるので、
必要なものは先に保存しておいてください。

## それでも困ったとき

無理に自分で直さず、サイトを渡してくれた人に **「この画面でこの表示が出た」**
とスクリーンショットを見せて相談してください。つまずきの多くは、公開URLの作成
（[post-deploy-guide.md](./post-deploy-guide.md) の手順④）か、パスワードの入れ間違いです。
