# Portfolio Kit 購入対応の手順

対象: Portfolio Kit の購入通知を受け取り、購入者へ最初の案内を送る秋さん。

購入が入ったら、**24時間以内に設置リンクまたは素材の案内をメールで送る**ための手順です。
設置リンクは公開せず、購入者へ個別に送ります。

用語メモ:

- Stripe: クレジットカード決済と購入通知を管理するサービス。
- リダイレクト先: 支払いが終わったあと、自動で購入者に表示するページ。
- Railway: Portfolio Kit のサイトをインターネット上に設置して公開するサービス。
- 引き渡しカード: 購入者が公開後に使う入口だけを5項目にまとめた案内。

## 最初に1回だけ確認すること

Stripe ダッシュボードを開き、セルフ（¥10,000）とおまかせ（¥30,000）の両方で確認します。
設定画面の名前は Stripe の更新で少し変わることがあります。

- [ ] 秋さんのアカウントで、支払い成功の通知メールが有効になっている
- [ ] 支払い完了後のリダイレクト先が `https://akieguchi.com/portfolio-kit/start` になっている
- [ ] 購入者へ領収書メールを自動送信する設定が有効になっている
- [ ] 決済画面で購入者のメールアドレスを収集する設定が有効になっている
- [ ] 2つの決済リンクをテスト表示し、購入者のメールアドレス欄があることを確認した

確認後は、この手順書に確認日をメモしておきます。

- 確認日: 2026-07-16（通知メール・リダイレクト先・領収書メールの3点をオーナー確認済み）

## 購入通知が届いたら

1. Stripe の入金通知メールを開く。
2. Stripe ダッシュボードで該当する支払いを開き、`成功` または `支払い済み` になっていることを確認する。
3. 購入者の名前、メールアドレス、購入プラン、支払日時を確認する。
4. **支払日時から24時間以内**に、下の該当する文面を送る。
5. 送信済みであることと送信日時を、購入記録に残す。

通知メールだけで判断できない場合は、必ず Stripe ダッシュボードの支払い状態を確認します。
支払いが未完了・返金済み・不明な場合は、設置リンクを送らずに確認を優先します。

## おまかせ設定から納品まで

購入者の素材を受け取ったら、次の順で進めます。

- [ ] Railway に購入者用のサイトを設置し、公開URLが開くことを確認する
- [ ] サイト名、プロフィール、連絡先、SNS、管理画面用パスワードを初期設定する
- [ ] 最初の写真を投入し、トップと作品一覧で表示を確認する
- [ ] 購入者自身が管理画面へログインできることを確認する
- [ ] 次の「引き渡しカード」5項目を、1通のメールにまとめて渡す

引き渡しカードの5項目は、`/portfolio-kit/start` の HANDOFF CARD と同じ内容です。

1. あなたのサイトURL
2. 管理画面URL
3. 管理パスワード
4. 最初に入れる写真
5. 困った時の連絡先

管理パスワードはメール本文へ直接書かず、できれば別の安全な方法で渡します。
メールで渡す場合は、サイトURLや管理画面URLとは別のメールに分けます。

## 困ったときの一次対応

まず `https://akieguchi.com/portfolio-kit/start` の **TROUBLESHOOTING** を購入者と一緒に確認します。

解決しない場合は、次の3枚を送ってもらいます。

- Railway のプロジェクト全体画面
- `eguchi-portfolio-app` サービスの Logs 画面
- `eguchi-portfolio-app` サービスの Variables のキー名一覧

Logs: サイトが動くときの記録や、止まった理由を表示する画面。

Variables: サイトを動かすための設定項目を保存する画面。

パスワードや `SECRET_ACCESS_KEY` などの値は、スクリーンショットに映さないよう伝えます。
購入者の写真、設定、Railway のサービスを削除せず、状況を記録してから保守担当へ相談します。
