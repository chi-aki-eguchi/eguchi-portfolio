## 1. 検索とSNSでの見つかりやすさ（SEO/SNS）

**SEO** = 検索エンジン（Google など）で見つかりやすくするための整備のこと。

### 現状（土台はすでに良い）

- sitemap.xml（検索エンジン向けのページ一覧）は写真画像込みで自動生成済み
- robots.txt / OGP（SNS共有時のプレビュー画像・文言）/ JSON-LD（検索エンジン向けのページ説明ラベル）も実装済み
- つまり「技術的なSEO」はほぼ完了していて、足りないのは **言葉と運用**

### やること（順番どおり）

1. **Google Search Console 登録**（無料。検索での表示回数・検索語が見える管理画面）
   — オーナー作業10分。どの言葉で見つかっているかが分かって初めて次が打てる
2. **シリーズごとのステートメント（2〜3行の説明文）を書く**
   — 検索エンジンは文章を手がかりにする。写真だけのページは見つけてもらいにくい。
   既存の series 説明欄に入れるだけでコード変更不要
3. **狙う言葉を3つ決める**（例:「ポートレート 撮影 [地域名]」「フィルム 作品撮り」など）
   — プロフィール・シリーズ説明に自然に織り込む
4. **SNS運用の型を作る**: 新シリーズ公開時に「OGP付きリンク + 一言」を投稿する、を習慣化。
   docs/sns-announcement.md の型を流用

### 秋さんが決めること

- 狙う言葉3つ（撮影ジャンル × 地域 × フィルム/デジタル などの組み合わせ）

## 4. コンシェルジュの3段価格（全込みコース新設）

### 現状の2コース（docs/sales-page.md）

- A. 自分で立てる — ¥10,000（手順書つきテンプレート）
- B. おまかせ設定 — ¥30,000（初期設定の代行）

### 提案: C. 全込みコース を追加して3段にする

**C に含めるもの（案）**: B の内容 + 独自ドメイン（akieguchi.com のような自分の住所となる URL）の
取得サポート + ドメイン接続設定 + 初回の写真アップロード代行（例: 30枚まで）+ 公開後7日間の相談

**価格の考え方（秋さんが決める）**: B との差分は「ドメイン周りの作業 + 写真流し込み」。
作業時間ベースで **¥50,000〜¥60,000 + ドメイン実費（年1,500〜2,000円程度）** が目安。
A:B:C = 1:3:5 の比率は「真ん中を選ばせる」価格設計としても機能する。

**運用上の注意（重要）**: ドメインは **購入者本人の名義・本人のアカウントで取得してもらう**。
秋さんのアカウントで代理取得すると、解約・移管・更新料の管理がずっと秋さんに残ってしまう。
「画面共有しながら一緒に取得する（30分）」を C の provided 内容として明記するのが安全。

### 秋さんが決めること

- C の価格と含める範囲（写真何枚まで・相談期間）
- 決定後: 販売ページ・スタートページ・運用手順書（docs/portfolio-kit-operations.md）への反映を実装

## 5. プリント販売の土台

### 方針: 小さく検証する。全カタログ販売はしない

1. **第0段階（仕組みなし・今すぐ可能）**: 1シリーズから3〜5点を選び、
   Stripe Payment Link（決済ページを1枚作るだけの仕組み。コード不要）で販売。
   サイト側は該当シリーズページに「Prints available — お問い合わせ」の一文を足すだけ
2. **決めておくこと（販売前に必須）**:
   - サイズと価格（例: A4 / A3 の2種)
   - エディション（限定◯部にするか、オープンにするか）
   - 印刷方法（自宅プリント / ラボ発注）と発送方法・送料
   - 納期の約束（Kit と同じく「◯日以内」の型を流用）
3. **第1段階（反応があったら）**: photos テーブルに「販売中」フラグを足して
   サイト上に購入導線を常設。**ここは DB 変更を伴うので反応を見てから**

### 秋さんが決めること

- 最初に売るシリーズと3〜5点の選定、サイズ・価格・エディション
- 印刷と発送の体制（ここが一番の実務）
