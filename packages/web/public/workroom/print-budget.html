NOTE 01

1冊の値段だけで、
決めない。

写真の本の予算を考えるときは、何冊作るかと、確認用の1冊を先に決めます。

最初に決める4つ

  1. 渡す相手：作品を見せる1冊か、会場で配る冊子か。見返す人と場面を一文にします。
  2. 冊数：必要な人数に、保管用と試し刷りを分けて足します。
  3. 写真の見せ方：1枚を大きく見るページと、流れを読むページを分けます。
  4. 受取日：発送予定と手元に届く日を分けて確認します。

試し刷りで見るところ

画面の明るさのまま印刷物を予測しません。最も暗い写真、顔や質感を見せる写真、文字の小さなページを確認用に入れます。見開きの中央に大事な被写体がかかっていないか、文字がページの端に近すぎないかも見ます。
