## 1. Contact フォームラベルの日本語化（旧 Q-8）

背景: 2026-07-08 決定ログ「引き続き保留」項。Name / Email / Subject / Message /
Send などの既定ラベルが英語のまま。**設定値の変更のみで実現できる**
（contactFormName 等のキー。コード変更は不要のはず）。

やること（オーナー判断後に実施）:

1. 現在の該当キーと既定値を一覧化する（`api/index.ts` の GET /settings 参照）。
2. 日本語ラベル案を2トーン（例: 標準「お名前/メール/件名/内容/送信」、
   丁寧「お名前/メールアドレス/ご用件/メッセージ/送信する」）作り、
   **適用せずに停止**してオーナーの選択を待つ。
3. 承認後: 管理画面から設定値を変更するのは**オーナー自身**が行う
   （エージェントは本番 DB 書き込み禁止のため）。指示書としては
   「管理画面 Settings のどの欄に何を入れるか」の手順書を作って渡す。

成果物: 文言2案+設定手順書（決定ログまたは scratch/）。コード変更なし。

**オーナーへの選択肢**: 標準トーン案／丁寧トーン案／どちらも使わず英語のまま。

## 2. footerCtaLabel / About→Gallery 導線（旧 Q-9）

背景: 2026-07-08 決定ログ「保留」項。footerCtaLabel（フッターの控えめな
お問い合わせ導線。空=非表示）は未活用。About→Gallery の一言導線は一度見送り。

やること（オーナー判断後に実施）:

1. footerCtaLabel: 現在の表示ロジック（Layout）を確認し、文言案2つ+表示位置の
   スクショモックを作る。**適用せず停止**。
2. About→Gallery: 見送りの経緯（2026-07-08 ログ）を読み、導線を足す場合の
   最小案1つ（文言+位置）だけモックを作る。**適用せず停止**。
3. どちらも設定値/小差分で実現できる規模に収まらない場合は、その旨を書いて停止。

成果物: モック画像（scratch/）+ 各案の一言メリデメ（決定ログ）。コード変更なし。

**オーナーへの選択肢**: footerCtaLabelを使う／使わない、About→Gallery導線を
追加する／見送りのまま。

## 3. Lightbox キャプションの佇まい2案モック（旧 Q-10）

背景: p2-pending #2。Lightbox のキャプション（タイトル・メタ・シリーズリンク）の
見せ方を「雑誌的佇まい」（`docs/specs/design-spec.md`）に寄せる検討。

やること（オーナー判断後に実施）:

1. **Lightbox.tsx のロジックには一切触れない**（§ルール: 開閉・ズーム・先読みは不変更）。
2. Playwright + CSS 注入で2案のモックスクショを作る（例: A=下辺に細い帯・
   小さめ英字メタ、B=右下に縦積み・タイトルのみ強調）。ライト/ダーク両方。
3. スクショと各案の一言説明を残して**停止**。実装はオーナー承認後の別チケット。

成果物: `scratch/lightbox-caption-2026-07/` にスクショ+比較メモ。コード変更なし。

**オーナーへの選択肢**: A案／B案／現状のまま変更しない。
