# 写真セレクト便の検索入口と購入前体験

2026-10-01。SNSを使わずに、商品の使いどころと受取結果を判断できる入口を整える。

- 製品紹介の最初を「選ばれた写真と仕上げの希望を、元のファイル名で受け取る」に変更。無料12枚と有料13〜300枚の使い分けを明示する。価格・配布ソフトは変更しない。
- `/tools/photo-select-bin/request.html`：案件・用途・枚数・期限・返送方法から写真選定の依頼文を作る。ファイル名返信／写真セレクト便／共有リンクの3方式。無料で文章をコピー・保存できる。購入を必須にしない。
- `/tools/photo-select-bin/walkthrough.html`：実際の選定画面で選んだ写真・コメントを受取結果へつなぐ。返送を省略した体験であることを明記。出力JSONは配布中の無料版へ読み込める。
- 入力のある2ページとデモには解析・入力送信なし。紹介ページ・ガイドの既存GA4には入口クリックだけ追加する。クリックは購入ではない。
- 依頼文ページをオーナーのサイトマップに追加。体験・埋め込みデモは `noindex,follow`。既存のオーナー専用配信制限を維持し、配布先のサイトでは公開しない。

正本は非公開の作業フォルダ `work/select-bin/src`。このリポジトリには生成済みの公開ファイルだけを置く。有料ZIP・売上・顧客情報は含めない。

検証：Chromium/WebKitで実際の回答と無料版の互換性、CSV一致、未選択写真へのコメント保持、上限と空回答の案内、HTML入力の無害化、依頼文3方式、コピー不可時の代替、320/390/1440pxでの横はみ出しなし、入力ページから外部通信なし。配布中の有料・無料ZIPはSHA-256一致で不変を確認。サイト関連18テストと本番ビルド成功。最初のビルドは隔離フォルダの依存参照不足で失敗し、参照を修正後に成功した。

検索エンジンへの登録、訪問、実利用、実注文は公開後の実測で確認する。機能完成やクリックを収益化の達成と扱わない。
