## 1. Contact フォームラベルの日本語化（旧 Q-8）

背景: 2026-07-08 決定ログ「引き続き保留」項。Name / Email / Subject / Message /
Send などの既定ラベルが英語のまま。**設定値の変更のみで実現できる**
（contactFormName 等のキー。コード変更は不要のはず）。

やること（オーナー判断後に実施）:

1. 現在の該当キーと既定値を一覧化する（`api/index.ts` の GET /settings 参照）。
2. 日本語ラベル案を2トーン（例: 標準「お名前/メール/件名/内容/送信」、
   丁寧「お名前/メールアドレス/ご用件/メッセージ/送信する」）作り、
   **適用せずに停止**してオーナーの選択を待つ。
3. 承認後: 管理画面から設定値を変更するのは**オーナー自身**が行う
   （エージェントは本番 DB 書き込み禁止のため）。指示書としては
   「管理画面 Settings のどの欄に何を入れるか」の手順書を作って渡す。

成果物: 文言2案+設定手順書（決定ログまたは scratch/）。コード変更なし。

**オーナーへの選択肢**: 標準トーン案／丁寧トーン案／どちらも使わず英語のまま。

## 5. 特定商取引法に基づく表記ページ（design critique 2026-07-16）

背景: 日本国内で対価を取って販売する場合に必要な法定表記が見当たらない。
返金ポリシーの明記もFAQにない。

やること（オーナー判断後）: 事業者名・連絡先・住所の扱い（請求により遅滞なく開示、

フッター/販売ページからリンク。FAQに返金の1問を追加。

**オーナーへの選択肢**: 表記内容の方針（氏名/住所をどこまで書くか、返金条件）。
