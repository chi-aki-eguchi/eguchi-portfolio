# Portfolio Kit — 管理画面を中心に伝える

2026-09-05のオーナー依頼: 充実した機能、わかりやすさ、写真を自分で入れ替えられること、公開後の管理・変更が簡単なことを販売の主役にする。

## 実装

- 日英の冒頭、料金プラン、FAQ、納品説明、検索・共有の説明を、自分で更新できる価値に揃える。
- 管理画面の紹介を料金・購入説明より前へ移す。
- 写真管理・デザイン設定・プロフィールの実画面を切り替え、画像を拡大して見られる。
- 冒頭と末尾に実際の管理画面デモへの入口を置く。デモは登録不要で本番へ保存しないことを伝える。
- 「なんでも変えられる」と無制限の開発を約束せず、写真・文章・用意された設定を自分で変更できると明記する。新規機能や設定外の個別デザインは別相談。
- 既存Studio導線、価格、サポート条件、決済設定はこの依頼で変更しない。

## 実画面の出所

2026-09-05に公開中の `/admin/demo` を実ブラウザーで撮影したJPEG（日英各3画面、1440×1000）。写真はデモの公開写真、プロフィールはデモ用の値。外部へのAPI書き込みを遮断し、並び順の変更はデモ内だけに保存した。生成画像や架空の管理画面ではない。

`packages/web/public/portfolio-kit/` の画像は、管理画面の構成を変えた際に撮り直す。実画面の説明と図が食い違わないようにする。
