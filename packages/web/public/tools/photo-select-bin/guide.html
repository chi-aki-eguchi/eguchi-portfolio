PHOTO SELECTION GUIDE

依頼主に写真を
選んでもらう手順。

写真選びで行き違いが起こりやすいのは、似た写真の番号、依頼の期限、選んだ後の返送方法です。最初にこの3点をそろえると、やり取りを進めやすくなります。

1. 確認用の写真を用意する

原本は別に保管し、JPEGなどの確認用コピーを使います。ファイル名は撮影から納品まで変えないのが基本です。同じファイル名が別フォルダーにある場合は、コピーに案件名などを加えて区別してください。

2. 選んでもらう条件を伝える

「何枚まで」「いつまで」「何のための写真か」を伝えます。たとえばプロフィール写真を3枚選んでほしい場合、SNS用・Web掲載用のように用途も書くと、相手が判断しやすくなります。

3. 閲覧ファイルをつくる

写真セレクト便で写真を追加し、選択上限と説明を設定します。閲覧用HTMLと、自分が保管する案件JSONの両方を保存してください。閲覧ファイルは、自分で一度開いて確認します。

4. 相手にファイルを渡す

相手に送るのは閲覧用HTMLだけです。送信前に利用してよい共有先を合意し、写真を含むファイルであることを伝えます。HTMLを扱えないメールではZIPにまとめ、受信者に解凍してPCブラウザで開いてもらいます。

相手への案内文

写真の候補をお送りします。PCでファイルをダウンロードし、Chrome・Edge・Safariなどのブラウザで開いてください。ZIPの場合は先に解凍してください。

使いたい写真を選び、必要に応じてコメントを書いてください。枚数・期限は今回の案内に記載した条件をご確認ください。

最後にお名前を入力し、「回答ファイルを保存」を押してください。保存したJSONファイルを、今回お渡ししたのと同じ連絡方法で返送いただくと完了です。保存しただけでは、こちらには届きません。

開けない場合は無理に操作せず、お使いのOSとブラウザをお知らせください。写真を含む閲覧ファイルは、関係者以外に転送しないでください。

5. 回答を元の写真と照合する

案件JSONを読み込み、返送された回答を開きます。選択されたファイル名とコメントを確認し、原本から必要な仕上げを行います。写真セレクト便の確認画像を、そのまま最終納品に使わないでください。

スマホだけで確認したい相手には

この方法はPCでのファイル操作が前提です。相手がスマートフォンしか使わない場合や、ファイルの受け渡しに慣れていない場合は、共有リンクで開ける別のギャラリーサービスなどを検討してください。
